# BS-C-002: Graph Shortest Path (Dijkstra's Algorithm)

**Tier**: Complex
**Category**: Algorithms
**Estimated LOC**: 90-130

## Task Description

Implement Dijkstra's algorithm to find the shortest path from a source node to all other nodes in a weighted, directed graph with non-negative edge weights.

## Requirements

### Functional Requirements

1. Accept a graph representation and source node as input
2. Calculate shortest distances from source to all reachable nodes
3. Return a mapping of node to shortest distance
4. Handle unreachable nodes (distance = infinity or large value)
5. Use Dijkstra's algorithm (greedy, priority-queue based)

### Input Specification

- **graph**: A representation of the graph:
  - Option 1: Adjacency list (dictionary/map where each node maps to list of (neighbor, weight) pairs)
  - Option 2: Edge list (list of (from_node, to_node, weight) tuples)
- **source**: The starting node
- **Return**: A mapping (dictionary/map) from each node to its shortest distance from source

### Constraints

- Number of nodes: 1 to 10,000
- Number of edges: 0 to 100,000
- Edge weights: non-negative integers (0 to 1,000,000)
- Graph may be disconnected
- May contain self-loops or multiple edges between same nodes (use minimum weight)
- Time complexity: O((V + E) log V) using priority queue
- Space complexity: O(V + E)

## Examples

### Example 1: Simple connected graph

**Input**:
```
graph = {
  'A': [('B', 1), ('C', 4)],
  'B': [('C', 2), ('D', 5)],
  'C': [('D', 1)],
  'D': []
}
source = 'A'
```

**Output**:
```
{
  'A': 0,
  'B': 1,
  'C': 3,
  'D': 4
}
```

**Explanation**:
- A -> A: 0 (starting point)
- A -> B: 1 (direct edge)
- A -> C: 3 (via B: A->B->C = 1+2 = 3, better than direct A->C = 4)
- A -> D: 4 (via B->C: A->B->C->D = 1+2+1 = 4)

### Example 2: Disconnected graph

**Input**:
```
graph = {
  'A': [('B', 1)],
  'B': [],
  'C': [('D', 1)],
  'D': []
}
source = 'A'
```

**Output**:
```
{
  'A': 0,
  'B': 1,
  'C': infinity,  // or very large number like 999999999
  'D': infinity
}
```

**Explanation**:
- A and B are connected
- C and D are unreachable from A

### Example 3: Single node

**Input**:
```
graph = {
  'A': []
}
source = 'A'
```

**Output**:
```
{
  'A': 0
}
```

**Explanation**:
- Only source node, distance 0 to itself

### Example 4: Multiple paths

**Input**:
```
graph = {
  'A': [('B', 5), ('C', 2)],
  'B': [('D', 1)],
  'C': [('B', 1), ('D', 5)],
  'D': []
}
source = 'A'
```

**Output**:
```
{
  'A': 0,
  'B': 3,
  'C': 2,
  'D': 4
}
```

**Explanation**:
- A -> B: 3 (via C: A->C->B = 2+1 = 3, better than direct A->B = 5)
- A -> C: 2 (direct)
- A -> D: 4 (via C->B: A->C->B->D = 2+1+1 = 4)

## Notes

**Dijkstra's Algorithm Steps**:
1. Initialize distances: source = 0, all others = infinity
2. Create priority queue (min-heap) with (distance, node) pairs
3. Mark all nodes as unvisited
4. While priority queue not empty:
   a. Extract node with minimum distance
   b. If already visited, skip
   c. Mark as visited
   d. For each neighbor:
      - Calculate distance = current_distance + edge_weight
      - If distance < neighbor's current distance:
        - Update neighbor's distance
        - Add (distance, neighbor) to priority queue
5. Return distance mapping

**Data Structures**:
- **Priority Queue (Min-Heap)**: Extract minimum distance node in O(log V)
- **Distance Map**: Track shortest known distance to each node
- **Visited Set**: Track processed nodes

**Common Mistakes**:
- Not using priority queue (results in O(V²) instead of O((V+E) log V))
- Not marking nodes as visited (may process same node multiple times)
- Not handling unreachable nodes (should be infinity)
- Incorrectly updating distances (not checking if new path is shorter)
- Not initializing source distance to 0
- Processing visited nodes again (efficiency issue)
- Integer overflow with large distances (use appropriate data type)

**Why Dijkstra's Works**:
- Greedy algorithm: always processes closest unvisited node
- Once node processed, its distance is final (no negative weights)
- Builds shortest path tree from source

**Limitations**:
- Only works with non-negative edge weights
- For negative weights, use Bellman-Ford algorithm instead

**Graph Representation Conversion**:
If given edge list instead of adjacency list:
```
edges = [('A', 'B', 1), ('A', 'C', 4), ...]
adjacency_list = {}
for from_node, to_node, weight in edges:
    if from_node not in adjacency_list:
        adjacency_list[from_node] = []
    adjacency_list[from_node].append((to_node, weight))
```
