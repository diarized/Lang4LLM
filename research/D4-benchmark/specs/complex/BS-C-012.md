# BS-C-012: Matrix Multiplication

**Tier**: Complex
**Category**: Mathematics
**Estimated LOC**: 80-110

## Task Description

Implement a matrix arithmetic module that supports multiplication of two matrices with compatible dimensions, matrix transposition, and determinant computation for matrices up to 3×3. The module must validate dimension compatibility before operations and return informative errors for invalid inputs.

## Requirements

### Functional Requirements

1. Support `multiply(A, B)` to multiply matrix A (n×m) by matrix B (m×p), returning an n×p matrix
2. Validate that the number of columns in A equals the number of rows in B before multiplying; signal an error if incompatible
3. Support `transpose(A)` that returns a new matrix where rows and columns are swapped (n×m becomes m×n)
4. Support `determinant(A)` for square matrices of size 1×1, 2×2, and 3×3
5. Signal an error when determinant is requested for a non-square matrix or a matrix larger than 3×3
6. Represent each matrix as a two-dimensional structure of numbers (rows of rows)
7. All operations must return new matrices without modifying the input matrices

### Input Specification

- **Matrix**: A two-dimensional collection of numbers, organized as a list of rows, where each row is a list of numbers of equal length
- **multiply(A, B)**:
  - A: matrix with n rows and m columns (n >= 1, m >= 1)
  - B: matrix with m rows and p columns (p >= 1)
  - Returns: matrix with n rows and p columns
- **transpose(A)**:
  - A: any matrix (n rows, m columns)
  - Returns: matrix with m rows and n columns
- **determinant(A)**:
  - A: square matrix of size 1×1, 2×2, or 3×3
  - Returns: a single number (the scalar determinant value)

### Constraints

- Matrix dimensions: at most 100×100 for multiplication
- All matrix entries are real numbers (floating point or integer)
- Determinant only supported for 1×1, 2×2, and 3×3 square matrices
- Dimension mismatch must be reported as an error, not silently ignored
- No external linear algebra libraries allowed

## Examples

### Example 1: Basic 2×2 matrix multiplication

**Operations**:
```
A = [[1, 2], [3, 4]]         // 2×2 matrix
B = [[5, 6], [7, 8]]         // 2×2 matrix
result = multiply(A, B)
// result = [[19, 22], [43, 50]]
```

**Explanation**:
- result[0][0] = 1*5 + 2*7 = 5 + 14 = 19
- result[0][1] = 1*6 + 2*8 = 6 + 16 = 22
- result[1][0] = 3*5 + 4*7 = 15 + 28 = 43
- result[1][1] = 3*6 + 4*8 = 18 + 32 = 50

### Example 2: Non-square multiplication (2×3 times 3×2)

**Operations**:
```
A = [[1, 2, 3], [4, 5, 6]]              // 2×3
B = [[7, 8], [9, 10], [11, 12]]         // 3×2
result = multiply(A, B)
// result = [[58, 64], [139, 154]]       // 2×2
```

**Explanation**:
- result[0][0] = 1*7 + 2*9 + 3*11 = 7 + 18 + 33 = 58
- result[0][1] = 1*8 + 2*10 + 3*12 = 8 + 20 + 36 = 64
- result[1][0] = 4*7 + 5*9 + 6*11 = 28 + 45 + 66 = 139
- result[1][1] = 4*8 + 5*10 + 6*12 = 32 + 50 + 72 = 154

### Example 3: Transpose operation

**Operations**:
```
A = [[1, 2, 3], [4, 5, 6]]    // 2×3
T = transpose(A)
// T = [[1, 4], [2, 5], [3, 6]]  // 3×2
```

**Explanation**:
- Row 0 of A becomes column 0 of T
- Row 1 of A becomes column 1 of T
- T[i][j] = A[j][i] for all valid i, j

### Example 4: Determinant calculations

**Operations**:
```
A1x1 = [[7]]
det1 = determinant(A1x1)
// det1 = 7

A2x2 = [[1, 2], [3, 4]]
det2 = determinant(A2x2)
// det2 = (1*4) - (2*3) = 4 - 6 = -2

A3x3 = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
det3 = determinant(A3x3)
// det3 = 0  (rows are linearly dependent)
```

**Explanation**:
- 1×1 determinant: the single element
- 2×2 determinant: ad - bc
- 3×3 determinant: cofactor expansion along first row

### Example 5: Dimension mismatch error

**Operations**:
```
A = [[1, 2], [3, 4]]       // 2×2
B = [[1, 2], [3, 4], [5, 6]]  // 3×2
result = multiply(A, B)
// Error: A has 2 columns, B has 3 rows — incompatible dimensions
```

**Explanation**:
- Multiplication requires A's column count to equal B's row count
- 2 ≠ 3, so the operation must fail with an error, not produce garbage output

## Notes

**Implementation Strategies**:

- Matrix multiplication core: triple nested loop (rows of A, columns of B, inner dimension)
- Result[i][j] accumulates the dot product of row i of A with column j of B
- Transpose: allocate result of swapped dimensions, then T[j][i] = A[i][j]
- 2×2 determinant: `a*d - b*c`
- 3×3 determinant via cofactor expansion:
  - `a*(ei - fh) - b*(di - fg) + c*(dh - eg)` where the matrix is [[a,b,c],[d,e,f],[g,h,i]]

**Common Mistakes**:
- Accessing rows and columns in the wrong order during multiplication (row/column index confusion)
- Building the result matrix with the wrong dimensions (n×p not m×m)
- Using the wrong cofactor sign in 3×3 determinant (alternating + - + pattern)
- Mutating input matrices instead of returning new ones
- Not validating squareness before determinant (silently computing garbage)

**Edge Cases**:
- 1×1 matrix: all three operations must work correctly
- Singular matrix (determinant = 0): valid result, not an error
- Multiplying a matrix by its transpose always yields a square result
