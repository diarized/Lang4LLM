# BS-C-009: Simple Pattern Matcher (Glob-Style)

**Tier**: Complex
**Category**: String Processing
**Estimated LOC**: 60-90

## Task Description

Implement a glob-style pattern matcher that determines whether a given string matches a pattern. The pattern may contain two special characters: asterisk (*), which matches zero or more of any character, and question mark (?), which matches exactly one of any character. All other characters in the pattern match only themselves (case-sensitive). Return true if the entire string matches the entire pattern, false otherwise.

## Requirements

### Functional Requirements

1. Accept a pattern string and an input string and return true if the string matches the pattern in full, false otherwise
2. The asterisk (*) in the pattern matches zero or more characters of any kind (including no characters and including other special characters as literal characters in the input)
3. The question mark (?) in the pattern matches exactly one character of any kind
4. All other characters in the pattern match exactly themselves, case-sensitively
5. Matching must be total: the pattern must account for every character in the input string and the entire input string must be consumed; partial matches are not accepted
6. Multiple consecutive asterisks in the pattern are equivalent to a single asterisk

### Input Specification

- **pattern**: A string — length 0 to 100; may contain *, ?, and any printable character
- **text**: A string — length 0 to 1,000; the string to match against the pattern
- **Return**: A boolean — true if text matches pattern, false otherwise

### Constraints

- Pattern length: 0 to 100 characters
- Text length: 0 to 1,000 characters
- Characters: printable ASCII
- Case-sensitive matching
- No built-in regular expression libraries allowed
- Expected complexity: at most O(n * m) where n = text length, m = pattern length

## Examples

### Example 1: Exact match (no wildcards)

**Input**: pattern = "hello", text = "hello"
**Output**: true

**Input**: pattern = "hello", text = "world"
**Output**: false

**Explanation**: Without wildcards, pattern and text must be identical character by character.

### Example 2: Question mark wildcard

**Input**: pattern = "h?llo", text = "hello"
**Output**: true

**Input**: pattern = "h?llo", text = "hllo"
**Output**: false

**Input**: pattern = "?", text = "a"
**Output**: true

**Input**: pattern = "?", text = ""
**Output**: false

**Explanation**: Each ? must match exactly one character. An empty string cannot satisfy ?.

### Example 3: Asterisk wildcard

**Input**: pattern = "he*", text = "hello"
**Output**: true

**Input**: pattern = "he*", text = "he"
**Output**: true (asterisk matches zero characters)

**Input**: pattern = "*", text = ""
**Output**: true (asterisk matches zero characters)

**Input**: pattern = "*", text = "anything"
**Output**: true

**Input**: pattern = "*.txt", text = "file.txt"
**Output**: true

**Input**: pattern = "*.txt", text = "file.csv"
**Output**: false

**Explanation**: * matches any span of characters (including empty). *.txt must end with ".txt".

### Example 4: Multiple wildcards

**Input**: pattern = "a*b*c", text = "aXXbYYc"
**Output**: true

**Input**: pattern = "a*b*c", text = "ac"
**Output**: false (no 'b' between a and c in text)

**Input**: pattern = "a*b*c", text = "abc"
**Output**: true (* matches empty in both positions)

**Input**: pattern = "**", text = "hello"
**Output**: true (consecutive asterisks equivalent to single *)

### Example 5: Empty inputs

**Input**: pattern = "", text = ""
**Output**: true (empty pattern matches empty string)

**Input**: pattern = "", text = "a"
**Output**: false (empty pattern matches nothing except empty string)

**Input**: pattern = "*", text = ""
**Output**: true

## Notes

**Implementation Strategy — Dynamic Programming**:
- Build a 2D boolean table where table[i][j] = true if the first i characters of the text match the first j characters of the pattern
- Base case: table[0][0] = true (empty text matches empty pattern)
- Pattern prefix of only asterisks: table[0][j] = true if pattern[0..j] consists entirely of *
- Recurrence:
  - If pattern[j-1] is a literal character or ?: match only if table[i-1][j-1] is true and (pattern matches ? or pattern[j-1] == text[i-1])
  - If pattern[j-1] is *: table[i][j] = table[i][j-1] (use * as empty match) OR table[i-1][j] (use * to consume one more character from text)
- Answer: table[len(text)][len(pattern)]

**Alternative Strategy — Recursive with Memoization**:
- Recursively match pattern[p..] against text[t..]
- Cache results for (p, t) to avoid exponential blowup
- When pattern[p] is *, try matching zero characters (recurse p+1, t) or one more character (recurse p, t+1)

**Consecutive Asterisks**:
- The DP approach handles consecutive asterisks naturally without preprocessing
- Alternatively, collapse consecutive asterisks in a preprocessing step

**Common Mistakes**:
- Allowing partial matches (matching only a prefix of text against pattern) — must check that all text is consumed
- Treating ? as zero-or-one instead of exactly one character
- Exponential backtracking in a naive recursive approach without memoization (e.g., "a*a*a*a*" against "aaaa...b")
- Forgetting to initialize the first row of the DP table for patterns starting with *
- Off-by-one errors in DP table indexing (table is sized (len(text)+1) x (len(pattern)+1))
