# BS-C-013: Polynomial Arithmetic

**Tier**: Complex
**Category**: Mathematics
**Estimated LOC**: 70-100

## Task Description

Implement a polynomial arithmetic module where polynomials are represented as ordered lists of coefficients (index = exponent). The module must support addition, subtraction, multiplication, evaluation at a given point, and symbolic differentiation, all operating on the coefficient list representation.

## Requirements

### Functional Requirements

1. Represent a polynomial as a list of numbers where the element at position i is the coefficient of x^i (position 0 = constant term, position 1 = coefficient of x, etc.)
2. Support `add(P, Q)` that adds two polynomials and returns the result polynomial
3. Support `subtract(P, Q)` that subtracts Q from P and returns the result polynomial
4. Support `multiply(P, Q)` that multiplies two polynomials and returns the result polynomial
5. Support `evaluate(P, x)` that computes the numeric value of polynomial P at the given point x
6. Support `derivative(P)` that returns a new polynomial representing the symbolic derivative of P
7. All operations must handle polynomials of differing degrees correctly (treat missing high-degree terms as zero)
8. Result polynomials must have no trailing zero coefficients at the high end (normalized form), except the zero polynomial which is represented as a single-element list containing zero

### Input Specification

- **Polynomial P**: A non-empty list of numbers; P[i] is the coefficient of x^i
  - Example: [3, 0, -1, 2] represents 3 - x^2 + 2x^3
  - The zero polynomial: [0]
- **add(P, Q)**: Two polynomials; returns polynomial
- **subtract(P, Q)**: Two polynomials; returns polynomial
- **multiply(P, Q)**: Two polynomials; returns polynomial
- **evaluate(P, x)**: Polynomial P and a real number x; returns a real number
- **derivative(P)**: Polynomial P; returns polynomial (degree decreases by one)

### Constraints

- Coefficients are real numbers (floating point or integer)
- Degree of input polynomials: at most 100
- Results must be normalized (no trailing zeros except zero polynomial)
- No symbolic computation libraries allowed
- evaluate must use efficient computation (Horner's method preferred but not required)

## Examples

### Example 1: Addition of polynomials

**Operations**:
```
P = [1, 2, 3]        // 1 + 2x + 3x^2
Q = [0, -1, 0, 4]    // -x + 4x^3
R = add(P, Q)
// R = [1, 1, 3, 4]  // 1 + x + 3x^2 + 4x^3
```

**Explanation**:
- Coefficients are added at each matching degree
- P has degree 2, Q has degree 3; missing terms in P treated as 0
- Result: [1+0, 2+(-1), 3+0, 0+4] = [1, 1, 3, 4]

### Example 2: Subtraction

**Operations**:
```
P = [5, 3, 2]    // 5 + 3x + 2x^2
Q = [5, 3, 2]    // same polynomial
R = subtract(P, Q)
// R = [0]       // zero polynomial
```

**Explanation**:
- Subtracting equal polynomials yields zero
- Result normalized to [0], not [0, 0, 0]

### Example 3: Multiplication

**Operations**:
```
P = [1, 1]       // 1 + x
Q = [1, -1]      // 1 - x
R = multiply(P, Q)
// R = [1, 0, -1]  // 1 - x^2
```

**Explanation**:
- (1 + x)(1 - x) = 1 - x + x - x^2 = 1 - x^2
- Result: coefficient 0 = 1*1 = 1; coefficient 1 = 1*(-1) + 1*1 = 0; coefficient 2 = 1*(-1) = -1

### Example 4: Evaluation

**Operations**:
```
P = [2, 0, 1]    // 2 + x^2
evaluate(P, 3)   // 2 + 9 = 11
evaluate(P, 0)   // 2 + 0 = 2
evaluate(P, -2)  // 2 + 4 = 6
```

**Explanation**:
- Substitute x = 3: 2 + (3)^2 = 2 + 9 = 11
- All coefficients participate; zero coefficients contribute zero

### Example 5: Derivative

**Operations**:
```
P = [5, 3, 2, 1]    // 5 + 3x + 2x^2 + x^3
D = derivative(P)
// D = [3, 4, 3]    // 3 + 4x + 3x^2
```

**Explanation**:
- Derivative of constant term (degree 0) vanishes
- Derivative of c * x^n is n * c * x^(n-1)
- Coefficient i of result = (i+1) * P[i+1]
- Result: [1*3, 2*2, 3*1] = [3, 4, 3]

### Example 6: Derivative of constant and zero polynomial

**Operations**:
```
P = [7]          // constant polynomial: 7
D = derivative(P)
// D = [0]       // zero polynomial

Z = [0]          // zero polynomial
DZ = derivative(Z)
// DZ = [0]      // still zero
```

**Explanation**:
- Derivative of any constant is zero
- Result is always normalized to at least [0]

## Success Criteria

- [ ] Add and subtract correctly handle polynomials of differing degrees
- [ ] Multiply produces correct degree (degree(P) + degree(Q)) and coefficients
- [ ] Evaluate returns exact numeric result at given point
- [ ] Derivative reduces degree by one and applies power rule correctly

## Notes

**Implementation Strategies**:

- Coefficient list representation: index maps directly to exponent, simplifying index arithmetic
- Addition/subtraction: iterate up to max(len(P), len(Q)), treating out-of-bounds as 0
- Multiplication: result has degree deg(P) + deg(Q); for each i in P and j in Q, accumulate P[i]*Q[j] into result[i+j]
- Evaluation using Horner's method (iterating from highest to lowest degree): avoids repeated exponentiation, numerically stable
- Derivative: new_coeff[i] = (i+1) * P[i+1] for i from 0 to len(P)-2

**Normalization**:
- After any operation, strip trailing zeros from the high end
- Always keep at least one element; if all are zero, return [0]

**Common Mistakes**:
- Off-by-one in derivative indexing (confusing coefficient index with exponent)
- Forgetting to normalize results (leaving trailing zero coefficients)
- Multiplying into a result buffer of wrong length (needs deg(P) + deg(Q) + 1 slots)
- Treating the empty list as the zero polynomial instead of [0]
- Mutating input coefficient lists instead of creating new ones

**Edge Cases**:
- Zero polynomial as input to any operation
- Constant polynomial (degree 0) derivative
- Polynomial with only the leading coefficient non-zero
- Multiplying two single-term polynomials (monomials)
