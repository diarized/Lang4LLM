# BS-C-007: 0/1 Knapsack Problem

**Tier**: Complex
**Category**: Algorithms
**Estimated LOC**: 60-90

## Task Description

Given a set of items each with a weight and a value, and a knapsack with a fixed weight capacity, determine the maximum total value achievable by selecting a subset of items such that the total weight does not exceed the capacity. Each item may be included at most once (0/1 constraint). Return both the maximum value and the list of selected items.

## Requirements

### Functional Requirements

1. Accept a list of items, each described by a positive integer weight and a positive integer value, and a non-negative integer capacity
2. Return the maximum total value achievable without exceeding the capacity
3. Return the list of item indices (0-based) that are selected to achieve this maximum value; if multiple subsets produce the same maximum value, any valid selection is acceptable
4. If no items fit within the capacity, the maximum value is 0 and the selected item list is empty
5. If capacity is 0, the maximum value is 0 and the selected item list is empty
6. If the item list is empty, the maximum value is 0 and the selected item list is empty

### Input Specification

- **items**: A list of pairs, each pair being (weight, value) — weight and value are positive integers; list length 0 to 100
- **capacity**: A non-negative integer — maximum total weight allowed; range 0 to 10,000
- **Return**: A pair consisting of:
  - The maximum total value (a non-negative integer)
  - A list of 0-based item indices representing the selected items; may be in any order

### Constraints

- Number of items: 0 to 100
- Item weights: 1 to 1,000 each
- Item values: 1 to 10,000 each
- Capacity: 0 to 10,000
- Each item selected at most once (0/1 knapsack, not unbounded)
- No built-in optimization or combinatorial search libraries allowed
- Expected time complexity: O(n * capacity) via dynamic programming

## Examples

### Example 1: Basic selection

**Input**:
```
items = [(2, 6), (2, 10), (3, 12)]   // (weight, value)
capacity = 5
```

**Output**: maximum value = 22, selected items = [1, 2] (items with weight 2,value 10 and weight 3,value 12)

**Explanation**:
- Item 0: weight=2, value=6
- Item 1: weight=2, value=10
- Item 2: weight=3, value=12
- Taking items 1 and 2: total weight = 5, total value = 22
- Taking items 0 and 2: total weight = 5, total value = 18
- Taking items 0 and 1: total weight = 4, total value = 16
- Best is items 1 and 2 with value 22

### Example 2: No items fit

**Input**:
```
items = [(10, 100), (20, 200)]
capacity = 5
```

**Output**: maximum value = 0, selected items = []

**Explanation**:
- All items weigh more than the capacity of 5
- No items can be selected; maximum value is 0

### Example 3: All items fit

**Input**:
```
items = [(1, 5), (2, 8), (1, 3)]
capacity = 10
```

**Output**: maximum value = 16, selected items = [0, 1, 2]

**Explanation**:
- Total weight of all items = 4, which is within capacity 10
- Taking all items is optimal: value = 5 + 8 + 3 = 16

### Example 4: Capacity exactly met

**Input**:
```
items = [(3, 4), (4, 5), (2, 3), (1, 1)]
capacity = 6
```

**Output**: maximum value = 8, selected items = [1, 2] or [0, 1] ... (verify which is correct)

**Explanation**:
- Items 1 (weight=4,value=5) and 2 (weight=2,value=3): weight=6, value=8
- Items 0 (weight=3,value=4) and 2 (weight=2,value=3) and 3 (weight=1,value=1): weight=6, value=8
- Both are valid answers with maximum value 8; either selection is acceptable

### Example 5: Edge cases

**Input**: items = [], capacity = 100
**Output**: maximum value = 0, selected items = []

**Input**: items = [(5, 100)], capacity = 0
**Output**: maximum value = 0, selected items = []

**Input**: items = [(5, 100)], capacity = 5
**Output**: maximum value = 100, selected items = [0]

**Explanation**: Boundary cases handled without error

## Notes

**Implementation Strategy — Dynamic Programming**:
- Build a 2D table where table[i][w] = maximum value achievable using items 0 through i-1 with weight limit w
- Base case: table[0][w] = 0 for all w (no items available)
- Recurrence: for each item i and each weight limit w:
  - If item i's weight exceeds w: table[i][w] = table[i-1][w] (cannot include item)
  - Otherwise: table[i][w] = maximum of (table[i-1][w], table[i-1][w - weight_i] + value_i)
- Final answer: table[n][capacity]

**Recovering Selected Items**:
- Trace backward through the DP table starting at table[n][capacity]
- At each row i, if table[i][w] != table[i-1][w], item i-1 was included; subtract its weight from w and add its index to the result
- Continue until i = 0

**Space Optimization** (optional, not required):
- The table can be reduced to a 1D array of size (capacity+1) by iterating weights in reverse to avoid using updated values from the current row
- However, recovering the selected items requires the full 2D table or additional bookkeeping

**Common Mistakes**:
- Using a 1D DP array for space efficiency but failing to correctly recover the item selection (item tracking requires 2D or separate bookkeeping)
- Iterating capacity in the wrong direction for the 1D optimization (must go right-to-left to avoid picking the same item twice)
- Off-by-one errors in table dimensions (need n+1 rows and capacity+1 columns)
- Assuming greedy works: the item with the highest value-to-weight ratio is not always optimal
- Returning item indices into the DP table (1-based) instead of into the original items list (0-based)
