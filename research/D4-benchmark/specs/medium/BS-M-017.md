# BS-M-017: Power Function

**Tier**: Medium
**Category**: Algorithms
**Estimated LOC**: 25-35

## Task Description

Implement a function that computes base raised to the power of exponent (base^exponent) for non-negative integer exponents using the fast exponentiation by squaring algorithm. The result must be an exact integer. Do not use any built-in power or exponentiation operator/function.

## Requirements

### Functional Requirements

1. Accept a base integer and a non-negative integer exponent
2. Return the exact integer result of base^exponent
3. Implement the fast exponentiation (squaring) algorithm — not a simple loop of repeated multiplication
4. Handle exponent = 0: any base^0 equals 1 (including 0^0 = 1 for this spec)
5. Handle base = 0 with positive exponent: result is 0
6. Handle negative base values correctly (even exponents give positive result, odd exponents give negative result)

### Input Specification

- **base**: An integer (positive, negative, or zero)
- **exponent**: A non-negative integer (0 or greater)
- **Return**: An integer — the exact value of base^exponent

### Constraints

- Exponent range: 0 to 30 (to avoid integer overflow on most platforms)
- Base range: -100 to 100
- Do not use a built-in power function or operator (e.g., `**`, `pow()`, `Math.pow()`)
- Must use fast exponentiation (exponentiation by squaring) — O(log n) multiplications
- Result must be exact (no floating-point approximation)

## Examples

### Example 1: Basic positive base

**Input**: base = 2, exponent = 10
**Output**: 1024
**Explanation**: 2^10 = 1024; fast exponentiation reaches this in ~4 multiplications

### Example 2: Exponent zero

**Input**: base = 7, exponent = 0
**Output**: 1
**Explanation**: Any number raised to the power 0 equals 1

### Example 3: Base zero

**Input**: base = 0, exponent = 5
**Output**: 0
**Explanation**: 0^5 = 0

### Example 4: Base one

**Input**: base = 1, exponent = 100
**Output**: 1
**Explanation**: 1 raised to any power equals 1; fast exponentiation terminates quickly

### Example 5: Negative base with even exponent

**Input**: base = -3, exponent = 4
**Output**: 81
**Explanation**: (-3)^4 = (-3)*(-3)*(-3)*(-3) = 81 (positive result)

### Example 6: Negative base with odd exponent

**Input**: base = -3, exponent = 3
**Output**: -27
**Explanation**: (-3)^3 = (-3)*(-3)*(-3) = -27 (negative result)

### Example 7: Exponent one

**Input**: base = 13, exponent = 1
**Output**: 13
**Explanation**: Any number raised to the power 1 equals itself

### Example 8: Large exponent

**Input**: base = 2, exponent = 20
**Output**: 1048576
**Explanation**: 2^20 = 1,048,576; fast algorithm uses ~5 multiplications

## Test Cases

### Required Coverage

- Small positive base and small positive exponent
- Exponent = 0 (any base returns 1)
- Base = 0 with positive exponent
- Base = 1 with large exponent
- Base = -1 with even exponent (result = 1)
- Base = -1 with odd exponent (result = -1)
- Negative base with even exponent (positive result)
- Negative base with odd exponent (negative result)
- Exponent = 1 (returns base)
- Large exponent (20+) — verify correct result and O(log n) behavior

### Minimum Test Count

10 test cases

## Success Criteria

Implementation passes when:
- [ ] Returns exact integer results for all inputs
- [ ] base^0 returns 1 for any base
- [ ] 0^n returns 0 for positive n
- [ ] Negative base with even exponent returns positive result
- [ ] Negative base with odd exponent returns negative result
- [ ] Uses O(log exponent) multiplications (fast exponentiation), not O(exponent) (simple loop)

## Notes

**Common Mistakes**:
- Using a simple multiplication loop (O(n) multiplications) instead of squaring (O(log n))
- Handling the 0^0 case incorrectly (this spec defines it as 1)
- Losing track of the sign for negative bases over multiple squarings
- Integer overflow — with base up to 100 and exponent up to 30, results can be astronomically large; the spec limits exponent to 30 to mitigate but implementations should use 64-bit integers at minimum

**Fast Exponentiation Algorithm** (for reference):
- If exponent is 0: return 1
- If exponent is even: return power(base * base, exponent / 2)
- If exponent is odd: return base * power(base * base, (exponent - 1) / 2)

This can also be implemented iteratively using the binary representation of the exponent.
