# BS-M-021: Anagram Check

**Tier**: Medium
**Category**: String Processing
**Estimated LOC**: 30-40

## Task Description

Determine whether two given strings are anagrams of each other. Two strings are anagrams if they contain exactly the same characters in the same quantities, regardless of order. The comparison is case-insensitive and ignores spaces.

## Requirements

### Functional Requirements

1. Accept two strings as input
2. Return true if the strings are anagrams of each other, false otherwise
3. Comparison is case-insensitive (treat uppercase and lowercase as equal)
4. Ignore spaces when comparing (spaces do not count as characters)
5. Consider only the remaining characters after removing spaces and normalizing case
6. Two identical strings are anagrams of each other

### Input Specification

- **string_a**: A string of any printable characters
- **string_b**: A string of any printable characters
- **Return**: Boolean (true if anagram, false otherwise)

### Constraints

- String length: 0 to 10,000 characters each
- Do not use built-in sort or anagram-detection functions (implement character counting directly)
- Time complexity: O(n) where n is the total length of both strings
- Space complexity: O(k) where k is the number of distinct characters (bounded by alphabet size)

## Examples

### Example 1: Classic anagram

**Input**: string_a = "listen", string_b = "silent"
**Output**: true
**Explanation**: Both contain the same characters: e(1), i(1), l(1), n(1), s(1), t(1)

### Example 2: Case-insensitive anagram

**Input**: string_a = "Listen", string_b = "Silent"
**Output**: true
**Explanation**: After normalizing to lowercase, both are "listen" and "silent" — same characters

### Example 3: Not an anagram

**Input**: string_a = "hello", string_b = "world"
**Output**: false
**Explanation**: Different characters; "hello" has l(2), h(1), e(1), o(1) vs "world" has w(1), o(1), r(1), l(1), d(1)

### Example 4: Anagram with spaces

**Input**: string_a = "the morse code", string_b = "here come dots"
**Output**: true
**Explanation**: After removing spaces, both contain the same characters

### Example 5: Different lengths (after space removal)

**Input**: string_a = "abc", string_b = "ab"
**Output**: false
**Explanation**: Different total character counts; cannot be anagrams

### Example 6: Both empty strings

**Input**: string_a = "", string_b = ""
**Output**: true
**Explanation**: Two empty strings contain the same characters (none)

### Example 7: One empty, one non-empty

**Input**: string_a = "", string_b = "a"
**Output**: false
**Explanation**: Empty string cannot be anagram of non-empty string

### Example 8: Repeated characters

**Input**: string_a = "aab", string_b = "bba"
**Output**: false
**Explanation**: "aab" has a(2), b(1); "bba" has b(2), a(1) — counts differ

## Test Cases

### Required Coverage

- Basic anagram (all distinct characters)
- Anagram with repeated characters
- Case-insensitive comparison
- Strings with spaces (spaces ignored)
- Not an anagram (different character counts)
- Not an anagram (different lengths)
- Both strings empty
- One string empty, one non-empty
- Single character strings (match and no match)

### Minimum Test Count

9 test cases

## Success Criteria

- [ ] Returns true for all valid anagram pairs
- [ ] Returns false for all non-anagram pairs
- [ ] Comparison is case-insensitive
- [ ] Spaces are excluded from comparison
- [ ] Handles empty strings correctly
- [ ] Character counting is accurate for repeated characters

## Notes

**Common Mistakes**:
- Forgetting to normalize case before comparing
- Not removing spaces before counting
- Comparing sorted strings directly (acceptable but less efficient than counting)
- Assuming equal lengths guarantees anagram (need character count match too)
- Not handling empty string edge cases

**Implementation Approach**:
1. Normalize both strings: convert to same case, remove spaces
2. Check if lengths are equal; if not, return false immediately
3. Build a character frequency map for the first string
4. Subtract counts using the second string
5. If all counts reach zero, strings are anagrams

**Sorting Alternative**: Sorting both strings and comparing is O(n log n) but simpler to reason about. Character counting is O(n) and preferred.
