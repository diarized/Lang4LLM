# BS-M-032: Word Frequency from Text

**Tier**: Medium
**Category**: File I/O
**Estimated LOC**: 35-50

## Task Description

Given a multi-line string of natural language text, count the frequency of each word. The counting must be case-insensitive and must exclude punctuation attached to words. Return a mapping from each unique word to its occurrence count, sorted by frequency in descending order (and alphabetically for ties).

## Requirements

### Functional Requirements

1. Accept a multi-line text string as input
2. Split the text into words by whitespace (spaces, tabs, newlines)
3. Normalize each word to lowercase
4. Strip all leading and trailing punctuation characters from each word (characters that are not letters or digits)
5. Ignore any token that becomes empty after stripping punctuation
6. Count the occurrences of each normalized word
7. Return the results as a list of (word, count) pairs sorted by count descending; for equal counts, sort alphabetically by word ascending

### Input Specification

- **text**: A string of natural language text, possibly multi-line
- **Return**: A list of (word, count) pairs (or equivalent records), sorted by count descending, then alphabetically ascending for ties

### Constraints

- Text length: 0 to 1,000,000 characters
- Punctuation includes: `. , ! ? ; : ' " ( ) [ ] { } - — … /` and similar non-alphanumeric characters
- Hyphenated words (e.g., "well-known"): treat the entire hyphenated form as one token after punctuation stripping (the hyphen in the middle is preserved since it is not leading or trailing)
- Empty input returns an empty list
- Time complexity: O(n log n) due to sorting

## Examples

### Example 1: Simple sentence

**Input**: "the cat sat on the mat"
**Output**: [("the", 2), ("cat", 1), ("mat", 1), ("on", 1), ("sat", 1)]
**Explanation**: "the" appears twice (highest frequency); remaining words appear once (sorted alphabetically)

### Example 2: Case normalization

**Input**: "Hello hello HELLO"
**Output**: [("hello", 3)]
**Explanation**: All three occurrences normalized to lowercase "hello"

### Example 3: Punctuation stripping

**Input**: "Hello, world! Hello."
**Output**: [("hello", 2), ("world", 1)]
**Explanation**: Commas, exclamation marks, and periods stripped from word boundaries

### Example 4: Multi-line text

**Input**:
```
To be, or not to be,
that is the question.
```
**Output**: [("be", 2), ("to", 2), ("is", 1), ("not", 1), ("or", 1), ("question", 1), ("that", 1), ("the", 1)]
**Explanation**: "be" and "to" each appear twice; remaining words sorted alphabetically

### Example 5: Empty input

**Input**: ""
**Output**: []
**Explanation**: No words to count

### Example 6: Punctuation-only tokens discarded

**Input**: "wow!!! yes... no?"
**Output**: [("no", 1), ("wow", 1), ("yes", 1)]
**Explanation**: After stripping leading/trailing punctuation, "wow!!!" → "wow", "yes..." → "yes", "no?" → "no"; all count 1, sorted alphabetically

### Example 7: Numbers treated as words

**Input**: "item 1 item 2 item 1"
**Output**: [("item", 3), ("1", 2), ("2", 1)]
**Explanation**: Numeric tokens are counted as words; "item" appears 3 times

## Test Cases

### Required Coverage

- Simple repeated word (basic frequency count)
- Case normalization (uppercase, lowercase, mixed)
- Leading punctuation stripped ("(hello)" → "hello")
- Trailing punctuation stripped ("hello." → "hello")
- Both leading and trailing punctuation stripped
- Multi-line input
- Empty input (empty result)
- Tie-breaking by alphabetical order
- Tokens that become empty after stripping (discarded)
- Mixed alphabetic and numeric tokens

### Minimum Test Count

10 test cases

## Success Criteria

- [ ] Frequency counts are correct for all words
- [ ] Comparison is case-insensitive
- [ ] Leading and trailing punctuation stripped from each token
- [ ] Empty tokens (after stripping) are discarded
- [ ] Output sorted by frequency descending
- [ ] Ties in frequency broken alphabetically ascending
- [ ] Empty input returns empty result

## Notes

**Common Mistakes**:
- Splitting on fixed characters instead of any whitespace — use whitespace as the universal word boundary
- Stripping punctuation from the middle of words (only strip leading and trailing, not interior characters)
- Using case-sensitive comparison (forgetting to lowercase before counting)
- Incorrect sort order: count descending is primary, alphabetical ascending is secondary
- Including empty strings in the output after stripping all-punctuation tokens

**Punctuation Stripping**:
Strip characters from the left and right of each token until the boundary character is a letter or digit. Interior characters (including hyphens and apostrophes) are preserved. This means "don't" remains "don't" and "self-aware" remains "self-aware".

**Sort Order Example**:
If "apple" appears 3 times and "banana" appears 3 times, "apple" should appear before "banana" in the output (alphabetical tiebreaker).
