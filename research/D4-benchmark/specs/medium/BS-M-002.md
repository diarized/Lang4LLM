# BS-M-002: Palindrome Checker

**Tier**: Medium
**Category**: String Processing
**Estimated LOC**: 25-35

## Task Description

Determine if a given string is a palindrome (reads the same forwards and backwards), ignoring spaces, punctuation, and case.

## Requirements

### Functional Requirements

1. Accept a string as input
2. Check if string is a palindrome when:
   - Ignoring spaces
   - Ignoring punctuation and special characters
   - Treating uppercase and lowercase as equivalent
3. Return true if palindrome, false otherwise
4. Handle empty strings (considered palindromes)

### Input Specification

- **text**: A string (letters, numbers, spaces, punctuation)
- **Return**: Boolean (true if palindrome, false otherwise)

### Constraints

- Input length: 0 to 10,000 characters
- Case-insensitive comparison
- Ignore non-alphanumeric characters
- Time complexity: O(n)

## Examples

### Example 1: Simple palindrome

**Input**: "racecar"
**Output**: true
**Explanation**: Reads same forwards and backwards

### Example 2: Not a palindrome

**Input**: "hello"
**Output**: false
**Explanation**: "hello" ≠ "olleh"

### Example 3: Palindrome with spaces

**Input**: "A man a plan a canal Panama"
**Output**: true
**Explanation**: Ignoring spaces and case: "amanaplanacanalpanama" is palindrome

### Example 4: Palindrome with punctuation

**Input**: "Was it a car or a cat I saw?"
**Output**: true
**Explanation**: Ignoring punctuation/spaces/case: "wasitacaroracatisaw"

### Example 5: Single character

**Input**: "a"
**Output**: true
**Explanation**: Single character is always palindrome

### Example 6: Empty string

**Input**: ""
**Output**: true
**Explanation**: Empty string is considered palindrome

### Example 7: Numeric palindrome

**Input**: "12321"
**Output**: true
**Explanation**: Numbers can form palindromes too

### Example 8: Mixed alphanumeric

**Input**: "A1B2B1A"
**Output**: true
**Explanation**: Case-insensitive with numbers

## Notes

**Implementation Approaches**:
1. Clean string (remove non-alphanumeric, lowercase)
2. Compare cleaned string with its reverse
OR
1. Two-pointer approach from both ends
2. Skip non-alphanumeric characters
3. Compare characters case-insensitively

**Common Mistakes**:
- Not handling spaces correctly
- Not making comparison case-insensitive
- Not ignoring punctuation
- Inefficient string reversal (multiple passes)
- Not handling empty string edge case
