# BS-M-020: Run-Length Encoding

**Tier**: Medium
**Category**: String Processing
**Estimated LOC**: 25-35

## Task Description

Implement run-length encoding (RLE) to compress a string by replacing consecutive sequences of the same character with the count followed by the character. For example, "aaabbc" becomes "3a2b1c". Also implement the corresponding decoder that expands a run-length encoded string back to the original.

## Requirements

### Functional Requirements

1. Implement `encode(text)` — compress the input string using run-length encoding:
   - Scan the string left to right
   - For each group of consecutive identical characters, output the count followed by the character
   - A single character occurrence is encoded as "1" followed by the character (e.g., "a" → "1a")
2. Implement `decode(encoded)` — expand a run-length encoded string back to the original:
   - Parse alternating count and character pairs
   - Repeat each character by its specified count
   - Counts may be multi-digit integers (e.g., "12a" means 12 repetitions of "a")
3. Both functions must handle empty strings (return empty string)
4. The encode and decode functions must be inverses of each other: decode(encode(s)) == s for any valid input s

### Input Specification

- **encode input (text)**: A string of printable characters — may contain letters, digits, spaces, and symbols; may be empty
- **encode return**: A string of the encoded form (count followed by character, no separators)
- **decode input (encoded)**: A valid run-length encoded string — alternating counts (one or more digits) and single characters
- **decode return**: The original decoded string

### Constraints

- Input string length for encode: 0 to 10,000 characters
- Characters in encode input: any printable character (including digits and spaces)
- Counts in encoded strings: always positive integers (minimum 1)
- The encoded string for decode is guaranteed to be valid (well-formed alternating count-character pairs)
- Do not use regular expressions (implement character-by-character parsing)

## Examples

### Example 1: Basic encoding

**Input**: encode("aaabbc")
**Output**: "3a2b1c"
**Explanation**: 3 consecutive 'a's → "3a"; 2 consecutive 'b's → "2b"; 1 'c' → "1c"

### Example 2: No compression possible

**Input**: encode("abcde")
**Output**: "1a1b1c1d1e"
**Explanation**: Each character appears exactly once; all encoded as count=1

### Example 3: All same character

**Input**: encode("aaaaaaa")
**Output**: "7a"
**Explanation**: 7 consecutive 'a's encoded as single group

### Example 4: Basic decoding

**Input**: decode("3a2b1c")
**Output**: "aaabbc"
**Explanation**: "3a" → "aaa"; "2b" → "bb"; "1c" → "c"

### Example 5: Multi-digit count decoding

**Input**: decode("12a3b")
**Output**: "aaaaaaaaaaaabbb"
**Explanation**: "12a" means 12 repetitions of 'a'; "3b" means 3 repetitions of 'b'

### Example 6: Round-trip consistency

**Input**: encode("aabbccddee")
**Output**: "2a2b2c2d2e"
**Verification**: decode("2a2b2c2d2e") returns "aabbccddee"

### Example 7: Empty string

**Input**: encode(""), decode("")
**Output**: "", ""
**Explanation**: Empty input produces empty output for both functions

### Example 8: Single character

**Input**: encode("z")
**Output**: "1z"
**Explanation**: Single character encoded as "1" followed by the character

### Example 9: Digits as characters in input

**Input**: encode("111222")
**Output**: "31322"
**Explanation**: Three '1' characters → "31"; three '2' characters → "32"; note encoded string starts with counts then chars

## Test Cases

### Required Coverage

- String with multiple distinct runs of different lengths
- String with no runs (all characters distinct) — all counts are 1
- String where all characters are identical
- Encode then decode round-trip (decode(encode(s)) == s)
- Empty string for both encode and decode
- Single-character string
- Encoded string with multi-digit counts (e.g., "12a") for decode
- Input containing digit characters (verify encoder handles them as regular characters)
- Encoded string containing spaces as characters for decode

### Minimum Test Count

9 test cases

## Success Criteria

Implementation passes when:
- [ ] encode() correctly groups consecutive identical characters
- [ ] encode() outputs count then character for each group (including count=1 groups)
- [ ] decode() correctly expands alternating count-character pairs
- [ ] decode() handles multi-digit counts correctly
- [ ] decode(encode(s)) == s for all valid inputs
- [ ] Both functions return empty string for empty input

## Notes

**Common Mistakes**:
- encode(): Forgetting to output the last group after the loop ends (off-by-one in flush logic)
- encode(): Not resetting the count when the character changes
- decode(): Assuming counts are always single digits, failing on "12a" style input
- decode(): Treating digit characters in the original string incorrectly — in the encoded output, numbers are always counts, not data characters
- Round-trip failure when the original string contains digit characters: encode("1a") → "11a1a"; decode must correctly parse "11" as count 11 followed by character 'a', then "1" as count 1 followed by 'a'

**Encoding Format Unambiguity**: Since counts precede characters, and characters in the encoded string are always single characters following a complete count, parsing is unambiguous when done left-to-right consuming digits greedily until a non-digit is reached.
