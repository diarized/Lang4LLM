# BS-M-009: Word Frequency Counter

**Tier**: Medium
**Category**: Data Structures
**Estimated LOC**: 30-40

## Task Description

Given a string of text, count how many times each distinct word appears, then return the words and their counts sorted by frequency in descending order. Words with equal frequency should be sorted alphabetically (ascending) as a tiebreaker.

## Requirements

### Functional Requirements

1. Split the input text into individual words by whitespace
2. Normalize each word to lowercase before counting
3. Strip leading and trailing punctuation from each word (commas, periods, exclamation marks, question marks, colons, semicolons)
4. Count the frequency of each distinct normalized word
5. Return results sorted primarily by frequency descending, then alphabetically ascending for equal frequencies
6. Return an empty result for empty or whitespace-only input

### Input Specification

- **text**: A string of natural-language text — may contain letters, digits, whitespace, and punctuation
- **Return**: A list of pairs (or equivalent structure), each containing a word and its count, sorted as specified

### Constraints

- Input length: 0 to 10,000 characters
- Words are sequences of characters separated by whitespace
- Punctuation stripping applies only to leading and trailing characters of each token, not internal characters (e.g., "don't" stays "don't")
- Case normalization is required (all lowercase)
- Digits within words are preserved (e.g., "mp3" counts as a word)

## Examples

### Example 1: Simple repeated words

**Input**: "the cat sat on the mat the cat"
**Output**: [("the", 3), ("cat", 2), ("mat", 1), ("on", 1), ("sat", 1)]
**Explanation**: "the" appears 3 times, "cat" twice; single-count words sorted alphabetically

### Example 2: Mixed case input

**Input**: "Hello hello HELLO world"
**Output**: [("hello", 3), ("world", 1)]
**Explanation**: All variants of "hello" are normalized to lowercase and counted together

### Example 3: Trailing punctuation stripped

**Input**: "Good morning, morning! Is it morning?"
**Output**: [("morning", 3), ("good", 1), ("is", 1), ("it", 1)]
**Explanation**: Commas, exclamation marks, and question marks are stripped from word boundaries

### Example 4: Tiebreaker alphabetical sort

**Input**: "dog cat bird dog cat bird"
**Output**: [("bird", 2), ("cat", 2), ("dog", 2)]
**Explanation**: All words appear twice; alphabetical order breaks the tie

### Example 5: Empty input

**Input**: ""
**Output**: []
**Explanation**: No words to count; result is empty

### Example 6: Single word

**Input**: "hello"
**Output**: [("hello", 1)]
**Explanation**: One distinct word with frequency 1

## Test Cases

### Required Coverage

- Multiple words with distinct frequencies
- Mixed case input normalized to lowercase
- Trailing punctuation stripped correctly
- Tiebreaker: equal-frequency words sorted alphabetically
- Empty string input returns empty result
- Whitespace-only input returns empty result
- Single word input
- Text where all words have frequency 1 (all alphabetical)
- Internal punctuation preserved (e.g., "don't" treated as one word)

### Minimum Test Count

9 test cases

## Success Criteria

Implementation passes when:
- [ ] Word splitting correctly tokenizes on whitespace
- [ ] Lowercase normalization applied before counting
- [ ] Leading and trailing punctuation stripped from each token
- [ ] Results sorted by frequency descending
- [ ] Equal-frequency words sorted alphabetically ascending
- [ ] Empty and whitespace-only inputs return empty results

## Notes

**Common Mistakes**:
- Forgetting to normalize case before counting, causing "The" and "the" to be counted separately
- Stripping punctuation from the middle of words, splitting contractions (e.g., "don't" → "don" and "t")
- Sorting only by frequency and ignoring the alphabetical tiebreaker
- Reversing the tiebreaker direction (Z before A instead of A before Z)
- Including empty strings as words when splitting on multiple consecutive spaces

**Punctuation Scope**: Strip only from the leading and trailing ends of each whitespace-delimited token. Internal characters (hyphens in "well-known", apostrophes in "it's") are part of the word.
