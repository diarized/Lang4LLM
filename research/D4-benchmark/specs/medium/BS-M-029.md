# BS-M-029: Roman Numeral Converter

**Tier**: Medium
**Category**: Mathematics
**Estimated LOC**: 35-50

## Task Description

Convert a positive integer in the range 1 to 3999 into its Roman numeral string representation. Roman numerals use seven symbols and a subtractive notation for values 4, 9, 40, 90, 400, and 900.

## Requirements

### Functional Requirements

1. Accept a positive integer in the range [1, 3999] as input
2. Return the Roman numeral string representation of that integer
3. Use the standard Roman numeral symbols: I (1), V (5), X (10), L (50), C (100), D (500), M (1000)
4. Apply subtractive notation for the six special cases:
   - IV = 4, IX = 9
   - XL = 40, XC = 90
   - CD = 400, CM = 900
5. Do not accept values outside [1, 3999]; behavior for out-of-range input is undefined (may return error or empty string)

### Input Specification

- **number**: A positive integer in the range [1, 3999]
- **Return**: A string containing the Roman numeral representation (uppercase letters only)

### Constraints

- Input range: 1 to 3999 (inclusive)
- Output contains only the characters: I, V, X, L, C, D, M
- The maximum output length is 15 characters (for 3888 = MMMDCCCLXXXVIII)
- Do not use built-in Roman numeral conversion functions

## Examples

### Example 1: Simple value

**Input**: 3
**Output**: "III"
**Explanation**: 3 = I + I + I

### Example 2: Subtractive notation — 4

**Input**: 4
**Output**: "IV"
**Explanation**: 4 = 5 - 1, written as IV (not IIII)

### Example 3: Subtractive notation — 9

**Input**: 9
**Output**: "IX"
**Explanation**: 9 = 10 - 1, written as IX

### Example 4: Mixed symbols

**Input**: 1994
**Output**: "MCMXCIV"
**Explanation**: 1000 (M) + 900 (CM) + 90 (XC) + 4 (IV)

### Example 5: Maximum value

**Input**: 3999
**Output**: "MMMCMXCIX"
**Explanation**: 3000 (MMM) + 900 (CM) + 90 (XC) + 9 (IX)

### Example 6: Round values

**Input**: 1000
**Output**: "M"
**Explanation**: Exactly one symbol needed

### Example 7: Value requiring all subtractive forms

**Input**: 1949
**Output**: "MCMXLIX"
**Explanation**: 1000 (M) + 900 (CM) + 40 (XL) + 9 (IX)

### Example 8: Minimum value

**Input**: 1
**Output**: "I"
**Explanation**: Smallest representable Roman numeral

### Example 9: Value with D (500)

**Input**: 650
**Output**: "DCL"
**Explanation**: 500 (D) + 100 (C) + 50 (L)

## Success Criteria

- [ ] Correct output for all six subtractive notation cases (IV, IX, XL, XC, CD, CM)
- [ ] Correct additive repetition (e.g., III, XXX, MMM)
- [ ] Correct combination of additive and subtractive forms
- [ ] Minimum value (1) returns "I"
- [ ] Maximum value (3999) returns "MMMCMXCIX"
- [ ] Output contains only valid Roman numeral characters

## Notes

**Common Mistakes**:
- Using IIII instead of IV, VIIII instead of IX, etc. (not applying subtractive notation)
- Applying subtractive notation to invalid combinations (e.g., IL, VX, VC — these are not standard)
- Constructing the result in the wrong direction (must go from largest to smallest)
- Forgetting that subtractive pairs (CM, CD, XC, XL, IX, IV) must be treated as atomic units

**Standard Implementation Approach**:
Define a table of value-symbol pairs in descending order, including all 13 entries:
(1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
(100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
(10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")

Greedily subtract the largest value that fits into the remaining number, appending its symbol to the result, until the number reaches zero.

**Why This Works**: Because the table is ordered largest-to-smallest and includes all subtractive forms, the greedy approach always produces the canonical Roman numeral representation.
