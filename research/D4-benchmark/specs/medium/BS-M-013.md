# BS-M-013: Set Operations

**Tier**: Medium
**Category**: Data Structures
**Estimated LOC**: 30-40

## Task Description

Given two lists of integers (which may contain duplicates), compute three classical set operations: union (all distinct values from either list), intersection (values present in both lists), and difference (values in the first list but not in the second). Each result must be returned as a sorted list of distinct integers in ascending order.

## Requirements

### Functional Requirements

1. Implement `union(list_a, list_b)` — return a sorted list of all distinct integers that appear in either list_a or list_b (or both)
2. Implement `intersection(list_a, list_b)` — return a sorted list of integers that appear in both list_a and list_b
3. Implement `difference(list_a, list_b)` — return a sorted list of integers that appear in list_a but NOT in list_b
4. All three functions must remove duplicates from the result
5. All three functions must sort the result in ascending order
6. The input lists themselves are not modified

### Input Specification

- **list_a**: A list of integers — may be empty, may contain duplicates
- **list_b**: A list of integers — may be empty, may contain duplicates
- **Return** (all three functions): A sorted list of distinct integers

### Constraints

- Input list length: 0 to 1,000 elements each
- Integer values: any valid integer (positive, negative, zero)
- Duplicate elimination applies to the result, not necessarily to inputs
- Operations must be mathematically correct set operations
- Do not use built-in set type if the language provides one (implement using lists and dictionaries/frequency tables)

## Examples

### Example 1: Basic union

**Input**: list_a = [1, 2, 3], list_b = [3, 4, 5]
**Output**: [1, 2, 3, 4, 5]
**Explanation**: All distinct values from both lists, sorted

### Example 2: Basic intersection

**Input**: list_a = [1, 2, 3, 4], list_b = [3, 4, 5, 6]
**Output**: [3, 4]
**Explanation**: Only 3 and 4 appear in both lists

### Example 3: Basic difference

**Input**: list_a = [1, 2, 3, 4], list_b = [3, 4, 5, 6]
**Output**: [1, 2]
**Explanation**: 1 and 2 are in list_a but not in list_b; 3 and 4 are excluded because they appear in list_b

### Example 4: Duplicates in inputs

**Input**: list_a = [1, 1, 2, 3], list_b = [2, 2, 4]
**Output**: union=[1, 2, 3, 4], intersection=[2], difference=[1, 3]
**Explanation**: Duplicates within each input do not affect set semantics; each value counted once

### Example 5: Disjoint lists

**Input**: list_a = [1, 2], list_b = [3, 4]
**Output**: union=[1, 2, 3, 4], intersection=[], difference=[1, 2]
**Explanation**: No shared elements; intersection is empty; difference equals list_a as a set

### Example 6: Identical lists

**Input**: list_a = [1, 2, 3], list_b = [1, 2, 3]
**Output**: union=[1, 2, 3], intersection=[1, 2, 3], difference=[]
**Explanation**: Identical sets: union and intersection equal the set itself; difference is empty

### Example 7: One empty list

**Input**: list_a = [1, 2, 3], list_b = []
**Output**: union=[1, 2, 3], intersection=[], difference=[1, 2, 3]
**Explanation**: Union of a set with the empty set is the set; intersection with empty set is empty; difference with empty set is the original set

### Example 8: Negative integers

**Input**: list_a = [-3, -1, 0, 2], list_b = [-1, 1, 2]
**Output**: union=[-3, -1, 0, 1, 2], intersection=[-1, 2], difference=[-3, 0]
**Explanation**: Negative values are handled correctly; sorted ascending includes negatives before zero

## Test Cases

### Required Coverage

- Overlapping lists (partial shared elements) for all three operations
- Disjoint lists — intersection must be empty
- Identical lists — difference must be empty
- Duplicate values within input lists — result has no duplicates
- One or both lists empty
- Negative integers in inputs
- list_b is superset of list_a — difference must be empty
- list_a is superset of list_b — intersection equals list_b as a set
- Verify result is sorted ascending in all cases

### Minimum Test Count

9 test cases

## Success Criteria

Implementation passes when:
- [ ] union() returns all distinct values from both inputs, sorted
- [ ] intersection() returns only values present in both inputs, sorted
- [ ] difference() returns values in list_a not in list_b, sorted
- [ ] All results contain no duplicate values
- [ ] Empty input lists produce correct results for each operation
- [ ] Negative integers handled correctly in sorting

## Notes

**Common Mistakes**:
- Difference(A, B) is not symmetric — difference(A, B) != difference(B, A); the order of arguments matters
- Not deduplicating inputs before performing the operation, causing duplicates in the result
- Forgetting to sort the result, or sorting in descending instead of ascending order
- Implementing intersection as "values in list_a that also appear in list_b" correctly, but including duplicates from list_a when list_a contains repeated values

**Mathematical Definitions**:
- Union(A, B) = { x | x ∈ A or x ∈ B }
- Intersection(A, B) = { x | x ∈ A and x ∈ B }
- Difference(A, B) = { x | x ∈ A and x ∉ B }
