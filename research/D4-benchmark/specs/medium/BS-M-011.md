# BS-M-011: Min-Heap Insert and Extract

**Tier**: Medium
**Category**: Data Structures
**Estimated LOC**: 40-50

## Task Description

Implement a min-heap that supports inserting an integer and extracting the minimum integer. A min-heap is a complete binary tree where every node's value is less than or equal to its children's values, stored compactly in a list using index arithmetic for parent/child relationships.

## Requirements

### Functional Requirements

1. Implement `insert(value)` — add an integer to the heap while preserving the min-heap property (sift up after insertion)
2. Implement `extract_min()` — remove and return the smallest value in the heap while preserving the min-heap property (sift down after removal); signal an error or return null/none if the heap is empty
3. Implement `peek_min()` — return the smallest value without removing it; signal an error or return null/none if empty
4. Implement `size()` — return the number of elements currently in the heap
5. The heap starts empty

### Input Specification

- **insert(value)**: An integer — no return value
- **extract_min()**: No input — returns the minimum integer, or null/none/error if empty
- **peek_min()**: No input — returns the minimum integer without removal, or null/none/error if empty
- **size()**: No input — returns a non-negative integer

### Constraints

- Must use a list-based (array) representation; no tree node objects
- Parent of node at index i is at index (i - 1) / 2 (integer division)
- Left child of node at index i is at index 2*i + 1
- Right child of node at index i is at index 2*i + 2
- insert() time complexity: O(log n)
- extract_min() time complexity: O(log n)
- peek_min() and size() time complexity: O(1)
- No built-in heap or priority queue types allowed

## Examples

### Example 1: Basic insert and extract

**Input**: insert(5), insert(3), insert(8), insert(1), extract_min()
**Output**: extract_min() returns 1
**Explanation**: 1 is the smallest value; after insertion the heap property places it at the root

### Example 2: Repeated extract preserves order

**Input**: insert(5), insert(3), insert(8), insert(1), extract_min(), extract_min(), extract_min(), extract_min()
**Output**: returns 1, 3, 5, 8 in sequence
**Explanation**: Extracting minimum repeatedly yields values in ascending order

### Example 3: peek_min does not remove

**Input**: insert(4), insert(2), insert(7), peek_min(), peek_min(), extract_min()
**Output**: peek_min() returns 2, peek_min() returns 2, extract_min() returns 2
**Explanation**: peek_min() does not alter the heap

### Example 4: Insert duplicate values

**Input**: insert(3), insert(3), insert(1), extract_min(), extract_min(), extract_min()
**Output**: returns 1, 3, 3
**Explanation**: Duplicates are allowed; minimum is extracted first

### Example 5: Extract on empty heap

**Input**: extract_min() (on empty heap)
**Output**: error or null/none
**Explanation**: No elements to extract

### Example 6: size() tracking

**Input**: size(), insert(10), insert(5), size(), extract_min(), size()
**Output**: size() returns 0, 2, 1 at the three calls
**Explanation**: Size increases with insert and decreases with extract

## Success Criteria

Implementation passes when:
- [ ] insert() maintains the min-heap property after each insertion
- [ ] extract_min() always returns the global minimum
- [ ] extract_min() restores the min-heap property after removal
- [ ] peek_min() returns minimum without removing it
- [ ] Empty-heap operations handled without undefined behavior
- [ ] Repeated extraction produces values in non-decreasing order

## Notes

**Common Mistakes**:
- Sift-up: comparing with the wrong parent index (using i/2 instead of (i-1)/2)
- Sift-down: not checking both children and swapping with the smaller one
- Sift-down: not stopping when the node is smaller than both children
- Extract: replacing root with last element before removing last element from list (order matters)
- Off-by-one: using 1-based index formulas when the list is 0-based

**Algorithm for extract_min()**:
1. Save the root value (index 0) — this is the result
2. Move the last element to index 0, then remove the last position
3. Sift down from index 0: repeatedly swap with the smaller child until heap property is satisfied
