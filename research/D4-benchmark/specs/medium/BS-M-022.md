# BS-M-022: Reverse Words in Sentence

**Tier**: Medium
**Category**: String Processing
**Estimated LOC**: 30-40

## Task Description

Given a sentence as a string, reverse the order of the words while preserving exactly one space between each word in the output. Leading and trailing whitespace in the input should be ignored, and multiple consecutive spaces between words should be collapsed to a single space.

## Requirements

### Functional Requirements

1. Accept a string containing one or more words separated by whitespace
2. Reverse the order of words in the string
3. Return the reversed sentence with exactly one space between each word
4. Strip any leading or trailing whitespace from the result
5. Collapse multiple consecutive spaces between words into a single space
6. Preserve the original content of each individual word (do not reverse characters within words)

### Input Specification

- **sentence**: A string containing words separated by whitespace (spaces, tabs)
- **Return**: A string with words in reversed order, single spaces between words, no leading/trailing whitespace

### Constraints

- String length: 0 to 10,000 characters
- Words consist of printable non-whitespace characters
- Input may contain leading/trailing whitespace and multiple spaces between words
- An empty string or all-whitespace input returns an empty string

## Examples

### Example 1: Basic two-word reversal

**Input**: "Hello World"
**Output**: "World Hello"
**Explanation**: Two words swapped in order

### Example 2: Multiple words

**Input**: "the quick brown fox"
**Output**: "fox brown quick the"
**Explanation**: All four words reversed in order

### Example 3: Leading and trailing spaces stripped

**Input**: "  hello world  "
**Output**: "world hello"
**Explanation**: Leading/trailing spaces stripped, words reversed

### Example 4: Multiple spaces between words collapsed

**Input**: "foo   bar   baz"
**Output**: "baz bar foo"
**Explanation**: Multiple spaces between words treated as one separator; output has single spaces

### Example 5: Single word

**Input**: "lonely"
**Output**: "lonely"
**Explanation**: Single word reversed in order is the same word

### Example 6: Empty string

**Input**: ""
**Output**: ""
**Explanation**: Empty input produces empty output

### Example 7: All whitespace

**Input**: "     "
**Output**: ""
**Explanation**: Input with only spaces has no words; output is empty string

### Example 8: Words with punctuation

**Input**: "Hello, World!"
**Output**: "World! Hello,"
**Explanation**: Punctuation is part of the word and is not modified

## Test Cases

### Required Coverage

- Two-word sentence
- Sentence with four or more words
- Leading whitespace in input
- Trailing whitespace in input
- Multiple consecutive spaces between words
- Single word (no reversal needed)
- Empty string input
- All-whitespace input
- Words containing punctuation (preserved as-is)
- Mixed leading, trailing, and internal multiple spaces

### Minimum Test Count

10 test cases

## Success Criteria

- [ ] Words appear in reversed order
- [ ] Each pair of words is separated by exactly one space
- [ ] No leading or trailing whitespace in output
- [ ] Multiple input spaces are collapsed to one
- [ ] Individual word content is unchanged
- [ ] Empty and all-whitespace inputs return empty string

## Notes

**Common Mistakes**:
- Splitting on single space only — fails when multiple spaces are present; split on any whitespace sequence
- Forgetting to strip leading/trailing whitespace before or after splitting
- Reversing characters within words instead of reversing word order
- Not handling the empty string case (attempting to reverse an empty list)
- Leaving a trailing space when joining the reversed list

**Implementation Strategy**:
1. Split the input string on any whitespace, discarding empty tokens
2. Reverse the resulting list of words
3. Join the reversed list with a single space
