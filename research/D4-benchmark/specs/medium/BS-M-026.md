# BS-M-026: Sieve of Eratosthenes

**Tier**: Medium
**Category**: Mathematics
**Estimated LOC**: 30-45

## Task Description

Return all prime numbers up to and including a given limit n using the Sieve of Eratosthenes algorithm. The sieve works by iteratively marking the multiples of each prime as composite, leaving only primes unmarked.

## Requirements

### Functional Requirements

1. Accept a non-negative integer n as input
2. Return a list of all prime numbers in the range [2, n], inclusive
3. Return an empty list if n is less than 2
4. Use the Sieve of Eratosthenes algorithm (not trial division for each number)
5. The returned list must be in ascending order

### Input Specification

- **n**: A non-negative integer — the upper bound (inclusive) for the sieve
- **Return**: A list of integers, each a prime number, in ascending order; empty list if n < 2

### Constraints

- n range: 0 to 1,000,000
- Time complexity: O(n log log n)
- Space complexity: O(n) for the sieve array
- Do not use built-in prime-checking or prime-generation functions

## Examples

### Example 1: Small limit

**Input**: n = 10
**Output**: [2, 3, 5, 7]
**Explanation**: Primes up to 10 are 2, 3, 5, 7; 4, 6, 8, 9, 10 are composite

### Example 2: Limit of 2

**Input**: n = 2
**Output**: [2]
**Explanation**: 2 is the only prime ≤ 2 (and it is the only even prime)

### Example 3: Limit of 1

**Input**: n = 1
**Output**: []
**Explanation**: No primes ≤ 1 exist; smallest prime is 2

### Example 4: Limit of 0

**Input**: n = 0
**Output**: []
**Explanation**: No primes in empty range

### Example 5: Limit of 20

**Input**: n = 20
**Output**: [2, 3, 5, 7, 11, 13, 17, 19]
**Explanation**: All primes up to 20; 4, 6, 8, 9, 10, 12, 14, 15, 16, 18, 20 are composite

### Example 6: Limit is a prime

**Input**: n = 13
**Output**: [2, 3, 5, 7, 11, 13]
**Explanation**: 13 is prime and is included in the output

### Example 7: Limit is a composite

**Input**: n = 15
**Output**: [2, 3, 5, 7, 11, 13]
**Explanation**: 15 is composite (3 × 5) and is excluded from the output

## Notes

**Algorithm Description**:
1. Create a boolean array `is_prime` of size n+1, initialized to true
2. Set is_prime[0] = false and is_prime[1] = false
3. For each integer p from 2 to sqrt(n):
   - If is_prime[p] is true:
     - Mark all multiples of p starting from p*p as false (composite)
     - Start from p*p (not 2*p) because smaller multiples have already been marked
4. Collect all indices where is_prime[i] is true

**Common Mistakes**:
- Starting the inner loop at 2*p instead of p*p (correct but slower)
- Including 0 and 1 in the output (neither is prime)
- Off-by-one: using range [0, n) instead of [0, n] (misses n if n is prime)
- Not initializing the sieve correctly (all values must start as true/unmarked)
- Iterating p up to n instead of sqrt(n) (correct but inefficient)
