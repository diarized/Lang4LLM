# BS-M-030: Statistical Summary

**Tier**: Medium
**Category**: Mathematics
**Estimated LOC**: 40-55

## Task Description

Given a list of numbers, compute three descriptive statistics: the arithmetic mean (average), the median (middle value), and the mode (most frequently occurring value). Return all three values as a structured result.

## Requirements

### Functional Requirements

1. Accept a non-empty list of numbers as input
2. Compute the **mean**: sum of all values divided by the count; return as a float
3. Compute the **median**: middle value when the list is sorted
   - For odd-length lists: the middle element
   - For even-length lists: the arithmetic mean of the two middle elements
   - Return as a float
4. Compute the **mode**: the value that appears most frequently
   - If multiple values share the highest frequency, return the smallest such value
   - Return as the same type as the input elements (integer or float)
5. Return all three values (mean, median, mode) as a structured result (record, tuple, map, or named values)
6. Do not modify the original input list

### Input Specification

- **numbers**: A non-empty list of numbers (integers or floats; at least one element)
- **Return**: A structure containing:
  - **mean**: Float — arithmetic mean of the list
  - **median**: Float — median value of the list
  - **mode**: Number — most frequent value (smallest if tie)

### Constraints

- List length: 1 to 100,000 elements
- Element values: any finite number (integers and floats may be mixed)
- List is guaranteed non-empty
- All three statistics must be computed in O(n log n) time or better
- Do not use built-in statistics library functions

## Examples

### Example 1: Odd-length list

**Input**: [1, 2, 3, 4, 5]
**Output**: mean = 3.0, median = 3.0, mode = 1
**Explanation**: Mean = 15/5 = 3.0; median is middle element (3); each value appears once, so mode is the smallest (1)

### Example 2: Even-length list

**Input**: [1, 2, 3, 4]
**Output**: mean = 2.5, median = 2.5, mode = 1
**Explanation**: Mean = 10/4 = 2.5; median = (2+3)/2 = 2.5; each value appears once, mode = smallest = 1

### Example 3: Clear mode

**Input**: [1, 2, 2, 3, 4]
**Output**: mean = 2.4, median = 2.0, mode = 2
**Explanation**: Mean = 12/5 = 2.4; median = 2 (middle of sorted list); 2 appears twice (highest frequency)

### Example 4: Mode tie — return smallest

**Input**: [1, 1, 2, 2, 3]
**Output**: mean = 1.8, median = 2.0, mode = 1
**Explanation**: Mean = 9/5 = 1.8; median = 2; both 1 and 2 appear twice — return smallest (1)

### Example 5: Single element

**Input**: [42]
**Output**: mean = 42.0, median = 42.0, mode = 42
**Explanation**: All three statistics equal the single element

### Example 6: All elements identical

**Input**: [5, 5, 5, 5]
**Output**: mean = 5.0, median = 5.0, mode = 5
**Explanation**: All statistics equal the repeated value

### Example 7: Unsorted input

**Input**: [3, 1, 4, 1, 5, 9, 2, 6]
**Output**: mean = 3.875, median = 3.5, mode = 1
**Explanation**: Mean = 31/8 = 3.875; sorted = [1,1,2,3,4,5,6,9], median = (3+4)/2 = 3.5; 1 appears twice (mode)

### Example 8: Floating-point elements

**Input**: [1.5, 2.5, 2.5, 3.5]
**Output**: mean = 2.5, median = 2.5, mode = 2.5
**Explanation**: Mean = 10/4 = 2.5; median = (2.5+2.5)/2 = 2.5; 2.5 appears twice

## Notes

**Common Mistakes**:
- Integer division for mean (must use floating-point division)
- Not sorting the list before computing the median (sorting is required; do not modify the original)
- Computing mode by sorting only — a frequency map is cleaner and O(n)
- Mode tie-breaking: not specifying or incorrectly implementing the smallest-wins rule
- Confusing median index for even-length lists (use indices n/2 - 1 and n/2 on the sorted list)

**Median Index Formula** (0-indexed sorted list of length n):
- Odd n: element at index n // 2
- Even n: average of elements at indices (n // 2 - 1) and (n // 2)

**Mode Algorithm**:
Build a frequency map (value → count). Find the maximum count. Among all values with that count, return the minimum. This is O(n) in time and O(n) in space.
