# BS-M-023: Longest Common Prefix

**Tier**: Medium
**Category**: String Processing
**Estimated LOC**: 30-40

## Task Description

Given a list of strings, find the longest common prefix shared by all strings in the list. The common prefix is the longest string that is a prefix of every string in the input list.

## Requirements

### Functional Requirements

1. Accept a list of strings as input
2. Return the longest string that is a prefix of every string in the list
3. If no common prefix exists, return an empty string
4. If the list contains only one string, return that string itself as the prefix
5. If the list is empty, return an empty string
6. The comparison is case-sensitive

### Input Specification

- **strings**: A list of strings (may be empty)
- **Return**: A string representing the longest common prefix; empty string if none exists

### Constraints

- List length: 0 to 10,000 strings
- Each string length: 0 to 1,000 characters
- Strings may be empty
- Time complexity: O(S) where S is the total number of characters across all strings
- Case-sensitive comparison

## Examples

### Example 1: Common prefix exists

**Input**: ["flower", "flow", "flight"]
**Output**: "fl"
**Explanation**: "fl" is the longest prefix shared by all three strings; "flo" is not shared by "flight"

### Example 2: No common prefix

**Input**: ["dog", "racecar", "car"]
**Output**: ""
**Explanation**: No character is shared at position 0 across all strings

### Example 3: All strings identical

**Input**: ["test", "test", "test"]
**Output**: "test"
**Explanation**: When all strings are the same, the entire string is the common prefix

### Example 4: One string is the prefix of all others

**Input**: ["ab", "abc", "abcd"]
**Output**: "ab"
**Explanation**: "ab" is the shortest string and is a prefix of both longer strings

### Example 5: Single string in list

**Input**: ["onlyone"]
**Output**: "onlyone"
**Explanation**: With a single string, the entire string is its own longest common prefix

### Example 6: Empty list

**Input**: []
**Output**: ""
**Explanation**: No strings means no common prefix

### Example 7: List containing an empty string

**Input**: ["abc", "", "abcd"]
**Output**: ""
**Explanation**: An empty string has no prefix; the common prefix is empty

### Example 8: Strings with shared long prefix

**Input**: ["interview", "interact", "interface", "internal"]
**Output**: "inter"
**Explanation**: "inter" is common to all; "intera" is not present in "interview" or "internal"

## Notes

**Common Mistakes**:
- Not handling the empty list case (causes index errors)
- Not handling empty strings within the list (length-zero strings break character comparisons)
- Comparing pairs of strings rather than all strings against a running prefix
- Off-by-one errors when truncating the prefix
- Returning the shortest string without verifying it is actually a prefix of all others

**Implementation Strategies**:

*Horizontal scanning*: Start with the first string as the candidate prefix. Shorten it character by character until it matches the start of each subsequent string.

*Vertical scanning*: Compare column by column (position 0 across all strings, then position 1, etc.) and stop when a mismatch or string end is reached.

Both strategies have the same time complexity O(S). Vertical scanning stops early when a mismatch is found at the beginning.
