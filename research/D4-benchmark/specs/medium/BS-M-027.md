# BS-M-027: Matrix Addition

**Tier**: Medium
**Category**: Mathematics
**Estimated LOC**: 30-40

## Task Description

Given two matrices of the same dimensions represented as lists of lists of numbers, compute their element-wise sum and return the resulting matrix. Each element of the result matrix is the sum of the corresponding elements from the two input matrices.

## Requirements

### Functional Requirements

1. Accept two matrices (lists of lists of numbers) as input
2. Verify that both matrices have identical dimensions (same number of rows and same number of columns in each row)
3. Return a new matrix where each element is the sum of the corresponding elements from the two input matrices
4. If the two matrices have different dimensions, return an error indicator (null, empty list, or raise an error — specify which in the implementation)
5. The input matrices must not be modified

### Input Specification

- **matrix_a**: A list of rows, where each row is a list of numbers (integers or floats); dimensions n × m
- **matrix_b**: A list of rows, where each row is a list of numbers (integers or floats); same dimensions n × m
- **Return**: A new matrix of the same dimensions n × m containing element-wise sums; or an error indicator if dimensions mismatch

### Constraints

- Matrix dimensions: 1 × 1 to 1,000 × 1,000
- Element values: any integer or floating-point number
- Both matrices are rectangular (all rows have the same length)
- Time complexity: O(n × m)
- Space complexity: O(n × m) for the result matrix

## Examples

### Example 1: 2×2 integer matrices

**Input**:
- matrix_a = [[1, 2], [3, 4]]
- matrix_b = [[5, 6], [7, 8]]

**Output**: [[6, 8], [10, 12]]
**Explanation**: Element-wise: (1+5=6, 2+6=8), (3+7=10, 4+8=12)

### Example 2: 3×3 integer matrices

**Input**:
- matrix_a = [[1, 0, 0], [0, 1, 0], [0, 0, 1]]
- matrix_b = [[9, 8, 7], [6, 5, 4], [3, 2, 1]]

**Output**: [[10, 8, 7], [6, 6, 4], [3, 2, 2]]
**Explanation**: Identity matrix added to another matrix; only diagonal elements change

### Example 3: 1×1 matrix (scalar)

**Input**:
- matrix_a = [[7]]
- matrix_b = [[3]]

**Output**: [[10]]
**Explanation**: Single-element matrices; result is scalar sum

### Example 4: Floating-point elements

**Input**:
- matrix_a = [[1.5, 2.5], [3.0, 4.1]]
- matrix_b = [[0.5, 1.5], [1.0, 0.9]]

**Output**: [[2.0, 4.0], [4.0, 5.0]]
**Explanation**: Float arithmetic applied element-wise

### Example 5: Matrices with negative numbers

**Input**:
- matrix_a = [[-1, -2], [-3, -4]]
- matrix_b = [[1, 2], [3, 4]]

**Output**: [[0, 0], [0, 0]]
**Explanation**: Each element cancels its counterpart

### Example 6: Dimension mismatch (different row counts)

**Input**:
- matrix_a = [[1, 2], [3, 4]]
- matrix_b = [[1, 2]]

**Output**: error (null or empty or raised error)
**Explanation**: matrix_a has 2 rows, matrix_b has 1 row — incompatible dimensions

### Example 7: 1×3 row vector addition

**Input**:
- matrix_a = [[1, 2, 3]]
- matrix_b = [[4, 5, 6]]

**Output**: [[5, 7, 9]]
**Explanation**: Row vectors treated as 1×3 matrices

## Notes

**Common Mistakes**:
- Modifying input matrices instead of creating a new result matrix
- Not checking column count mismatch (checking only row count)
- Assuming all matrices are square; must handle n×m for arbitrary n and m
- Off-by-one in nested loop bounds

**Dimension Validation**:
Check that len(matrix_a) == len(matrix_b), and for each row index i, check that len(matrix_a[i]) == len(matrix_b[i]). Both checks are needed.

**Output Format**:
The result must be a full n×m list of lists, not a flattened list or any other structure.
