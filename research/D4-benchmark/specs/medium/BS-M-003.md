# BS-M-003: Merge Sorted Lists

**Tier**: Medium
**Category**: Data Structures
**Estimated LOC**: 30-40

## Task Description

Merge two sorted lists into a single sorted list, maintaining the sorted order.

## Requirements

### Functional Requirements

1. Accept two sorted lists as input
2. Merge them into a single list
3. Maintain sorted order (ascending)
4. Handle lists of different lengths
5. Handle empty lists
6. Do not modify original input lists

### Input Specification

- **list1**: A list of integers sorted in ascending order
- **list2**: A list of integers sorted in ascending order
- **Return**: A new list containing all elements from both lists, sorted

### Constraints

- List lengths: 0 to 10,000 elements each
- Input lists are already sorted
- Time complexity: O(n + m) where n and m are list lengths
- Space complexity: O(n + m) for output list
- Do not use built-in sort functions

## Examples

### Example 1: Equal length lists

**Input**: list1 = [1, 3, 5], list2 = [2, 4, 6]
**Output**: [1, 2, 3, 4, 5, 6]
**Explanation**: Elements from both lists interleaved

### Example 2: Different length lists

**Input**: list1 = [1, 5, 9], list2 = [2, 3, 4, 6, 7, 8]
**Output**: [1, 2, 3, 4, 5, 6, 7, 8, 9]
**Explanation**: All elements merged in order

### Example 3: One empty list

**Input**: list1 = [1, 2, 3], list2 = []
**Output**: [1, 2, 3]
**Explanation**: Merging with empty list returns non-empty list

### Example 4: Both empty lists

**Input**: list1 = [], list2 = []
**Output**: []
**Explanation**: Merging two empty lists yields empty list

### Example 5: No overlap

**Input**: list1 = [1, 2, 3], list2 = [4, 5, 6]
**Output**: [1, 2, 3, 4, 5, 6]
**Explanation**: Second list elements all larger

### Example 6: Duplicate values

**Input**: list1 = [1, 3, 5], list2 = [3, 5, 7]
**Output**: [1, 3, 3, 5, 5, 7]
**Explanation**: Duplicates from both lists preserved

### Example 7: Negative numbers

**Input**: list1 = [-5, -1, 3], list2 = [-3, 0, 2]
**Output**: [-5, -3, -1, 0, 2, 3]
**Explanation**: Works with negative numbers

## Notes

**Algorithm (Two Pointers)**:
1. Initialize two pointers (i=0, j=0) for list1 and list2
2. Compare elements at current pointers
3. Add smaller element to result, advance that pointer
4. When one list exhausted, append remaining elements from other list

**Common Mistakes**:
- Not handling empty lists
- Not appending remaining elements when one list exhausted
- Modifying input lists instead of creating new output
- Using nested loops (O(n*m) instead of O(n+m))
- Not preserving duplicates
- Incorrectly handling equal elements
