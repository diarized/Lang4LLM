# BS-M-024: Caesar Cipher

**Tier**: Medium
**Category**: String Processing
**Estimated LOC**: 30-45

## Task Description

Implement a Caesar cipher that shifts each letter in a string by a given number of positions in the alphabet. The cipher preserves the case of each letter, leaves non-letter characters unchanged, and wraps around the alphabet (after 'z' comes 'a', after 'Z' comes 'A'). Both encoding (positive shift) and decoding (negative shift) are supported.

## Requirements

### Functional Requirements

1. Accept a string and an integer shift value as input
2. Shift every letter in the string by the shift amount within its case group (a-z or A-Z)
3. Wrap around the alphabet: shifting 'z' by 1 gives 'a', shifting 'a' by -1 gives 'z'
4. Preserve the case of each letter (uppercase stays uppercase, lowercase stays lowercase)
5. Leave all non-letter characters (digits, punctuation, spaces) unchanged
6. Support negative shift values (used for decoding)
7. Support shift values larger than 25 or smaller than -25 (apply modulo 26)

### Input Specification

- **text**: A string containing any printable characters
- **shift**: An integer (may be negative, zero, or larger than 25)
- **Return**: A string of the same length with letters shifted, non-letters preserved

### Constraints

- String length: 0 to 100,000 characters
- Shift range: any integer (apply modulo 26 to normalize)
- Only letters (a-z, A-Z) are shifted; all other characters are passed through unchanged
- Time complexity: O(n) where n is the string length

## Examples

### Example 1: Basic shift

**Input**: text = "Hello", shift = 3
**Output**: "Khoor"
**Explanation**: H→K, e→h, l→o, l→o, o→r (each letter shifted 3 positions forward, case preserved)

### Example 2: Wrap around lowercase

**Input**: text = "xyz", shift = 3
**Output**: "abc"
**Explanation**: x→a, y→b, z→c (wraps from end to start of alphabet)

### Example 3: Wrap around uppercase

**Input**: text = "XYZ", shift = 3
**Output**: "ABC"
**Explanation**: X→A, Y→B, Z→C (uppercase wraps independently)

### Example 4: Non-letters unchanged

**Input**: text = "Hello, World! 123", shift = 13
**Output**: "Uryyb, Jbeyq! 123"
**Explanation**: Letters shifted by 13 (ROT13); comma, space, exclamation mark, digits unchanged

### Example 5: Negative shift (decode)

**Input**: text = "Khoor", shift = -3
**Output**: "Hello"
**Explanation**: Negative shift reverses the encoding; K→H, h→e, o→l, o→l, r→o

### Example 6: Zero shift

**Input**: text = "NoChange", shift = 0
**Output**: "NoChange"
**Explanation**: Zero shift leaves every character unchanged

### Example 7: Shift larger than 25

**Input**: text = "abc", shift = 29
**Output**: "efg"
**Explanation**: 29 mod 26 = 3; equivalent to shifting by 3

### Example 8: Shift of exactly 26

**Input**: text = "Hello", shift = 26
**Output**: "Hello"
**Explanation**: Full alphabet rotation returns to original positions

### Example 9: Empty string

**Input**: text = "", shift = 5
**Output**: ""
**Explanation**: Empty input produces empty output

## Notes

**Common Mistakes**:
- Applying modulo only to positive values — negative shifts also need proper modulo handling (e.g., -3 mod 26 = 23, not -3)
- Shifting non-letter characters when they should be preserved
- Mixing up ASCII offsets for uppercase (65) vs. lowercase (97)
- Not wrapping around correctly at the alphabet boundaries

**Modulo for Negative Values**:
In languages where the modulo of a negative number can be negative (e.g., -3 % 26 = -3), use `((shift % 26) + 26) % 26` to always get a non-negative result.

**Character Position Formula**:
For a letter `c` in range [base, base+25] where base is 65 (uppercase) or 97 (lowercase):
`result = base + ((c - base + shift) % 26 + 26) % 26`
