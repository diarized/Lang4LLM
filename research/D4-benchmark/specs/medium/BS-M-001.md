# BS-M-001: Binary Search

**Tier**: Medium
**Category**: Algorithms
**Estimated LOC**: 20-30

## Task Description

Implement binary search to find the position of a target value in a sorted list of integers.

## Requirements

### Functional Requirements

1. Search for a target value in a sorted list
2. Return the index (position) of the target if found
3. Return -1 or null if target not found
4. Assume input list is sorted in ascending order
5. Use binary search algorithm (divide-and-conquer approach)

### Input Specification

- **sorted_list**: A list of integers sorted in ascending order (no duplicates)
- **target**: An integer to search for
- **Return**: Integer index (0-based position) if found, -1 if not found

### Constraints

- List length: 0 to 100,000 elements
- Time complexity: O(log n)
- Space complexity: O(1) (iterative) or O(log n) (recursive)
- Do not use built-in search functions

## Examples

### Example 1: Target found in middle

**Input**: sorted_list = [1, 3, 5, 7, 9, 11], target = 7
**Output**: 3
**Explanation**: 7 is at index 3 (0-indexed)

### Example 2: Target at beginning

**Input**: sorted_list = [1, 3, 5, 7, 9, 11], target = 1
**Output**: 0
**Explanation**: 1 is at index 0

### Example 3: Target at end

**Input**: sorted_list = [1, 3, 5, 7, 9, 11], target = 11
**Output**: 5
**Explanation**: 11 is at index 5

### Example 4: Target not found (too large)

**Input**: sorted_list = [1, 3, 5, 7, 9, 11], target = 12
**Output**: -1
**Explanation**: 12 is not in the list

### Example 5: Target not found (too small)

**Input**: sorted_list = [1, 3, 5, 7, 9, 11], target = 0
**Output**: -1
**Explanation**: 0 is not in the list

### Example 6: Empty list

**Input**: sorted_list = [], target = 5
**Output**: -1
**Explanation**: Cannot find element in empty list

### Example 7: Single element (found)

**Input**: sorted_list = [5], target = 5
**Output**: 0
**Explanation**: 5 is at index 0

### Example 8: Single element (not found)

**Input**: sorted_list = [5], target = 3
**Output**: -1
**Explanation**: 3 is not in single-element list

## Notes

**Common Mistakes**:
- Off-by-one errors in index calculations
- Infinite loops when bounds not updated correctly
- Integer overflow in midpoint calculation (use `low + (high - low) / 2` instead of `(low + high) / 2`)
- Not handling empty list edge case
- Returning wrong index for boundary elements

**Algorithm Steps**:
1. Initialize low = 0, high = length - 1
2. While low <= high:
   - Calculate mid = low + (high - low) / 2
   - If target == list[mid], return mid
   - If target < list[mid], set high = mid - 1
   - If target > list[mid], set low = mid + 1
3. If not found, return -1
