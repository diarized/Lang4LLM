# BS-M-036: Shape Calculator

**Tier**: Medium
**Category**: Object-Oriented Design
**Estimated LOC**: 45-60

## Task Description

Implement three geometric shape types — Circle, Rectangle, and Triangle — each supporting area and perimeter calculations. All three types share a common interface: they can be created with their defining measurements and queried for their area and perimeter.

## Requirements

### Functional Requirements

1. **Circle** type:
   - Created with a radius (positive number)
   - area(): π × radius²
   - perimeter() (circumference): 2 × π × radius
   - Use π ≈ 3.141592653589793

2. **Rectangle** type:
   - Created with width and height (positive numbers)
   - area(): width × height
   - perimeter(): 2 × (width + height)

3. **Triangle** type:
   - Created with three side lengths a, b, c (positive numbers)
   - Validate that the three sides form a valid triangle (each side must be less than the sum of the other two); if invalid, signal an error
   - area(): computed using Heron's formula — s = (a+b+c)/2; area = sqrt(s × (s-a) × (s-b) × (s-c))
   - perimeter(): a + b + c

4. All area and perimeter results are returned as floating-point numbers
5. All three types must support the same method names (area and perimeter) enabling polymorphic usage

### Input Specification

- **Circle**: radius — a positive number
- **Rectangle**: width — a positive number; height — a positive number
- **Triangle**: a, b, c — three positive numbers representing side lengths
- **area()**: Returns a float — the area of the shape
- **perimeter()**: Returns a float — the perimeter of the shape

### Constraints

- All input dimensions must be positive (greater than zero); behavior for zero or negative inputs is undefined
- Triangle side validation: a + b > c, b + c > a, a + c > b; all three conditions must hold
- Area and perimeter values returned as floating-point (exact for rectangle with integer inputs is acceptable)
- Floating-point results for circle and triangle should be accurate to at least 4 decimal places

## Examples

### Example 1: Circle with radius 5

**Input**: Circle(radius = 5)
**Operations**:
- area() → 78.5398 (approximately π × 25)
- perimeter() → 31.4159 (approximately 2 × π × 5)

**Explanation**: Standard circle formulas applied with π ≈ 3.14159265

### Example 2: Rectangle 4 × 6

**Input**: Rectangle(width = 4, height = 6)
**Operations**:
- area() → 24.0
- perimeter() → 20.0

**Explanation**: Area = 4 × 6 = 24; perimeter = 2 × (4 + 6) = 20

### Example 3: Square (equal width and height)

**Input**: Rectangle(width = 5, height = 5)
**Operations**:
- area() → 25.0
- perimeter() → 20.0

**Explanation**: A square is a special case of rectangle

### Example 4: Equilateral triangle

**Input**: Triangle(a = 3, b = 3, c = 3)
**Operations**:
- area() → 3.8971 (approximately)
- perimeter() → 9.0

**Explanation**: s = 4.5; area = sqrt(4.5 × 1.5 × 1.5 × 1.5) ≈ 3.8971

### Example 5: Right triangle (3, 4, 5)

**Input**: Triangle(a = 3, b = 4, c = 5)
**Operations**:
- area() → 6.0
- perimeter() → 12.0

**Explanation**: Classic right triangle; area = 6 (also verifiable as base × height / 2 = 3 × 4 / 2)

### Example 6: Invalid triangle

**Input**: Triangle(a = 1, b = 2, c = 10)
**Operations**: Creating the triangle signals an error (sides do not satisfy triangle inequality)

**Explanation**: 1 + 2 = 3 < 10; these sides cannot form a triangle

### Example 7: Unit circle

**Input**: Circle(radius = 1)
**Operations**:
- area() → 3.1416 (approximately π)
- perimeter() → 6.2832 (approximately 2π)

## Notes

**Common Mistakes**:
- Using π = 3.14 instead of a more precise value (use the language's built-in math constant)
- Heron's formula: forgetting to take the square root at the end (computing s(s-a)(s-b)(s-c) without sqrt gives area squared)
- Triangle inequality: checking only one condition (e.g., a + b > c) instead of all three
- Returning integer results from rectangle area/perimeter when floating-point is required
- Not providing a shared interface for all three shapes (important for polymorphic usage in tests)

**Heron's Formula**:
s = (a + b + c) / 2
area = sqrt(s × (s - a) × (s - b) × (s - c))

**Triangle Inequality** (all three must hold):
- a + b > c
- b + c > a
- a + c > b

**Degenerate Triangle**: When the three sides satisfy the inequality with equality (e.g., 1, 2, 3 where 1+2=3), the triangle is degenerate (zero area, collinear points). Treat this as invalid.
