# BS-S-040: Check Substring

**Tier**: Simple
**Category**: Miscellaneous
**Estimated LOC**: 5-10

## Task Description

Determine whether a given substring appears anywhere within a given string and return a boolean result.

## Requirements

### Functional Requirements

1. Accept two strings as inputs: the text to search within and the substring to search for
2. Return true if the substring appears at least once in the text
3. Return false if the substring does not appear in the text
4. The search is case-sensitive
5. An empty substring is always considered to be present in any string

### Input Specification

- **text**: A string to search within (may be empty)
- **substring**: A string to search for (may be empty)
- **Return**: A boolean value (true if substring is found, false otherwise)

### Constraints

- Both inputs can be of any length (0 to 10,000 characters)
- Search is case-sensitive ('A' does not match 'a')
- An empty substring always returns true (it is trivially present in every string)
- The substring must appear as a contiguous sequence of characters
- No regular expression matching required; exact character matching only

## Examples

### Example 1: Substring present

**Input**: text = "hello world", substring = "world"
**Output**: true
**Explanation**: "world" appears at position 6 in "hello world"

### Example 2: Substring absent

**Input**: text = "hello world", substring = "xyz"
**Output**: false
**Explanation**: "xyz" does not appear anywhere in "hello world"

### Example 3: Case sensitivity

**Input**: text = "Hello World", substring = "hello"
**Output**: false
**Explanation**: "hello" (lowercase) does not match "Hello" (uppercase first letter)

### Example 4: Empty substring

**Input**: text = "anything", substring = ""
**Output**: true
**Explanation**: Empty string is always considered present

### Example 5: Empty text

**Input**: text = "", substring = "abc"
**Output**: false
**Explanation**: Cannot find non-empty substring in empty text

### Example 6: Both empty

**Input**: text = "", substring = ""
**Output**: true
**Explanation**: Empty substring is present in any string, including empty string

### Example 7: Substring equals full text

**Input**: text = "abc", substring = "abc"
**Output**: true
**Explanation**: The entire text is the substring

## Test Cases

### Required Coverage

- Substring present in the middle
- Substring present at the start
- Substring present at the end
- Substring absent
- Case mismatch (substring in wrong case)
- Empty substring (always true)
- Empty text with non-empty substring (false)
- Both empty (true)
- Substring longer than text (false)

### Minimum Test Count

9 test cases

## Success Criteria

- [ ] Returns true when substring is present in text
- [ ] Returns false when substring is absent
- [ ] Search is case-sensitive
- [ ] Empty substring returns true regardless of text
- [ ] Empty text returns false for any non-empty substring
- [ ] Both empty returns true

## Notes

Common mistakes:
- Performing a case-insensitive search when a case-sensitive search is required
- Treating the empty substring as not found instead of always found
- Not handling the edge case where the substring is longer than the text (should return false, not error)
