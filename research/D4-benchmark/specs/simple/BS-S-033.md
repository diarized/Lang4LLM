# BS-S-033: Read Lines from File

**Tier**: Simple
**Category**: File I/O
**Estimated LOC**: 5-10

## Task Description

Open a text file at a given path, read its contents, and return a list of lines with trailing newline characters removed from each line.

## Requirements

### Functional Requirements

1. Accept a file path as input
2. Open and read the text file at that path
3. Split the content into individual lines
4. Remove any trailing newline character from each line
5. Return the list of lines in order

### Input Specification

- **file_path**: A string representing a valid path to an existing text file
- **Return**: A list of strings, one per line, with trailing newlines stripped

### Constraints

- The file is guaranteed to exist and be readable
- File encoding: UTF-8
- Lines are separated by newline characters
- An empty file returns an empty list
- A file with one line (no newline at end) returns a list with one element
- A trailing newline at the end of the file does not produce an extra empty entry

### File Behavior

- File content "hello\nworld\n" → ["hello", "world"]
- File content "hello\nworld" → ["hello", "world"]
- File content "" → []
- File content "\n" → [""]

## Examples

### Example 1: Two-line file

**File content**: "line one\nline two\n"
**Output**: ["line one", "line two"]
**Explanation**: Two lines read, trailing newlines stripped

### Example 2: File without trailing newline

**File content**: "alpha\nbeta"
**Output**: ["alpha", "beta"]
**Explanation**: Both lines returned; no trailing newline to strip from second line

### Example 3: Empty file

**File content**: ""
**Output**: []
**Explanation**: No lines in empty file

### Example 4: Single line

**File content**: "only line"
**Output**: ["only line"]
**Explanation**: One entry in the list

### Example 5: Line that is itself empty

**File content**: "hello\n\nworld\n"
**Output**: ["hello", "", "world"]
**Explanation**: The blank line between "hello" and "world" becomes an empty string

## Test Cases

### Required Coverage

- Multi-line file with trailing newline
- Multi-line file without trailing newline
- Empty file
- Single-line file
- File with blank lines in the middle
- File with many lines

### Minimum Test Count

6 test cases

## Success Criteria

- [ ] Returns correct list of lines in order
- [ ] Strips trailing newlines from each line
- [ ] Returns empty list for empty file
- [ ] Does not produce a phantom empty entry from a final newline
- [ ] Preserves blank interior lines as empty strings

## Notes

Common mistakes:
- Splitting on newline naively and getting an extra empty string at the end when the file ends with a newline
- Not stripping carriage returns on files with Windows-style line endings (\r\n)
- Returning lines with newlines still attached
