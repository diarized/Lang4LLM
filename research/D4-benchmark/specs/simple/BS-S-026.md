# BS-S-026: Convert to Title Case

**Tier**: Simple
**Category**: String Processing
**Estimated LOC**: 10-15

## Task Description

Transform a string to title case, where the first letter of each whitespace-separated word is uppercased and all other letters in that word are lowercased.

## Requirements

### Functional Requirements

1. Accept a string as input
2. Split the string into whitespace-separated words
3. For each word, uppercase the first letter and lowercase the remaining letters
4. Reassemble the words with the same whitespace separators as the original
5. Return the title-cased string

### Input Specification

- **text**: A string (may contain letters, numbers, spaces, punctuation)
- **Return**: A string with the first letter of each word uppercased and remaining letters lowercased

### Constraints

- Input length: 0 to 10,000 characters
- Words are separated by single spaces (assume single-space separation in input)
- If a word starts with a non-letter character, that character is left unchanged
- Empty string returns empty string
- Time complexity: O(n)

## Examples

### Example 1: Simple sentence

**Input**: "hello world"
**Output**: "Hello World"
**Explanation**: First letter of each word uppercased, rest lowercased

### Example 2: Already title case

**Input**: "Hello World"
**Output**: "Hello World"
**Explanation**: No change needed; first letters already uppercase

### Example 3: All uppercase input

**Input**: "HELLO WORLD"
**Output**: "Hello World"
**Explanation**: Only first letter of each word stays uppercase, rest lowercased

### Example 4: Mixed case

**Input**: "the QUICK brown FOX"
**Output**: "The Quick Brown Fox"
**Explanation**: Each word normalized to title case regardless of original casing

### Example 5: Single word

**Input**: "python"
**Output**: "Python"
**Explanation**: Single word, first letter uppercased

### Example 6: Empty string

**Input**: ""
**Output**: ""
**Explanation**: Empty input returns empty output

## Test Cases

### Required Coverage

- Simple lowercase sentence
- Already title-cased string
- All-uppercase string
- Mixed case string
- Single word
- Empty string
- String with numbers in words
- String where words begin with non-letter characters

### Minimum Test Count

8 test cases

## Success Criteria

- [ ] First letter of each word is uppercased
- [ ] Remaining letters in each word are lowercased
- [ ] Word boundaries are preserved
- [ ] Empty string returns empty string
- [ ] Non-letter first characters in words are handled without error

## Notes

Common mistakes:
- Only uppercasing the first letter without lowercasing the rest
- Splitting on characters other than space (which may alter multi-space separators)
- Not handling words that begin with digits or punctuation
