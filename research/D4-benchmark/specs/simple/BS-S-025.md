# BS-S-025: Repeat String

**Tier**: Simple
**Category**: String Processing
**Estimated LOC**: 5-10

## Task Description

Produce a new string by concatenating a given string with itself a specified number of times.

## Requirements

### Functional Requirements

1. Accept a string and a non-negative integer count as inputs
2. Concatenate the string with itself exactly count times
3. Return the resulting repeated string
4. If count is 0, return an empty string

### Input Specification

- **text**: A string of any length (including empty)
- **count**: A non-negative integer specifying how many times to repeat the string
- **Return**: A string consisting of text repeated count times

### Constraints

- count range: 0 to 1,000
- Input string length: 0 to 1,000 characters
- Output length may be up to count * len(text) characters
- No external libraries required

## Examples

### Example 1: Normal repetition

**Input**: text = "ab", count = 3
**Output**: "ababab"
**Explanation**: "ab" concatenated 3 times

### Example 2: Count of zero

**Input**: text = "hello", count = 0
**Output**: ""
**Explanation**: Zero repetitions produces empty string

### Example 3: Count of one

**Input**: text = "hello", count = 1
**Output**: "hello"
**Explanation**: One repetition returns the string unchanged

### Example 4: Empty string input

**Input**: text = "", count = 5
**Output**: ""
**Explanation**: Repeating an empty string any number of times yields empty string

### Example 5: Single character repeated

**Input**: text = "x", count = 4
**Output**: "xxxx"
**Explanation**: 'x' concatenated 4 times

## Test Cases

### Required Coverage

- Normal multi-character string repeated multiple times
- Count of zero
- Count of one
- Empty string input with positive count
- Single character repeated
- String with spaces repeated

### Minimum Test Count

6 test cases

## Success Criteria

- [ ] Correctly concatenates string count times
- [ ] Returns empty string when count is 0
- [ ] Returns original string when count is 1
- [ ] Handles empty input string
- [ ] Produces exact character count (len(text) * count)

## Notes

Common mistakes:
- Off-by-one error (repeating count+1 or count-1 times)
- Not handling count = 0 (may return the original string instead of empty string)
- Building the result with a loop but initializing with the string instead of empty string
