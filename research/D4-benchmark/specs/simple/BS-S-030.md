# BS-S-030: Convert Celsius to Fahrenheit

**Tier**: Simple
**Category**: Mathematics
**Estimated LOC**: 5-10

## Task Description

Convert a temperature value from Celsius to Fahrenheit using the standard conversion formula and return the result as a floating-point number.

## Requirements

### Functional Requirements

1. Accept a temperature value in Celsius as input
2. Apply the conversion formula: Fahrenheit = Celsius * 9/5 + 32
3. Return the result as a floating-point number
4. The calculation must use floating-point (not integer) arithmetic

### Input Specification

- **celsius**: A numeric value (integer or decimal) representing temperature in Celsius
- **Return**: A floating-point number representing the equivalent temperature in Fahrenheit

### Constraints

- Input range: -273.15 to 10,000 (physically meaningful range includes absolute zero)
- Perform division as floating-point (9 divided by 5 equals 1.8, not 1)
- No external libraries required

## Examples

### Example 1: Freezing point of water

**Input**: 0
**Output**: 32.0
**Explanation**: 0 * 9/5 + 32 = 32.0 (freezing point in Fahrenheit)

### Example 2: Boiling point of water

**Input**: 100
**Output**: 212.0
**Explanation**: 100 * 9/5 + 32 = 180 + 32 = 212.0

### Example 3: Body temperature

**Input**: 37
**Output**: 98.6
**Explanation**: 37 * 9/5 + 32 = 66.6 + 32 = 98.6

### Example 4: Absolute zero

**Input**: -273.15
**Output**: -459.67
**Explanation**: -273.15 * 9/5 + 32 = -491.67 + 32 = -459.67

### Example 5: Negative Celsius

**Input**: -40
**Output**: -40.0
**Explanation**: -40 Celsius equals -40 Fahrenheit (the scales intersect at -40)

## Test Cases

### Required Coverage

- Freezing point (0°C → 32°F)
- Boiling point (100°C → 212°F)
- Body temperature (37°C → 98.6°F)
- Negative Celsius value
- The intersection point (-40°C → -40°F)
- Absolute zero (-273.15°C → -459.67°F)
- Room temperature (20°C → 68°F)

### Minimum Test Count

7 test cases

## Success Criteria

- [ ] Applies the correct formula (C * 9/5 + 32)
- [ ] Returns a floating-point result
- [ ] Correctly handles negative Celsius values
- [ ] Freezing and boiling point conversions are exact
- [ ] Does not use integer division (9/5 must equal 1.8, not 1)

## Notes

Common mistakes:
- Using integer division: computing 9/5 as 1 instead of 1.8 — multiply by 9 first then divide by 5, or use 1.8 as a literal
- Inverting the formula (applying F-to-C instead of C-to-F)
- Returning an integer result instead of a float
