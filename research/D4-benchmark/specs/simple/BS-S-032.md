# BS-S-032: Count Digits

**Tier**: Simple
**Category**: Mathematics
**Estimated LOC**: 5-10

## Task Description

Count the number of decimal digit characters (0 through 9) in a non-negative integer. The number 0 itself has exactly one digit.

## Requirements

### Functional Requirements

1. Accept a non-negative integer as input
2. Count the number of digits in its decimal representation
3. Return the count as a positive integer
4. Zero has exactly one digit

### Input Specification

- **number**: A non-negative integer (0 or greater)
- **Return**: A positive integer representing the number of decimal digits

### Constraints

- Input range: 0 to 10^15
- No string conversion required (may use repeated division by 10)
- Result is always at least 1
- No external libraries required

## Examples

### Example 1: Single digit

**Input**: 5
**Output**: 1
**Explanation**: 5 is a single-digit number

### Example 2: Two-digit number

**Input**: 42
**Output**: 2
**Explanation**: 42 has two digits: 4 and 2

### Example 3: Three-digit number

**Input**: 100
**Output**: 3
**Explanation**: 100 has three digits: 1, 0, and 0

### Example 4: Zero

**Input**: 0
**Output**: 1
**Explanation**: 0 is represented as a single digit

### Example 5: Large number

**Input**: 1000000
**Output**: 7
**Explanation**: 1,000,000 has seven digits

### Example 6: Boundary value

**Input**: 9
**Output**: 1
**Explanation**: 9 is a single-digit number (the largest single digit)

### Minimum Test Count

7 test cases

## Success Criteria

- [ ] Returns 1 for all single-digit inputs including 0
- [ ] Returns correct count for multi-digit numbers
- [ ] Handles zero specially (returns 1, not 0)
- [ ] Handles large numbers correctly

## Notes

Two common approaches:
1. Repeated division by 10 — divide the number by 10 until it reaches 0, counting iterations; initialize count to 0 and handle 0 as a special case, or initialize count to 1 and start loop only when number >= 10
2. Convert to string representation and count characters

Common mistakes:
- Returning 0 for input 0 instead of 1
- Off-by-one in the division loop (loop continues one too many or too few times)
