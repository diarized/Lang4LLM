# BS-S-015: Factorial

**Tier**: Simple
**Category**: Algorithms
**Estimated LOC**: 5-15

## Task Description

Compute the factorial of a non-negative integer n, defined as the product of all positive integers from 1 to n inclusive, with 0! equal to 1 by convention.

## Requirements

### Functional Requirements

1. Accept a single non-negative integer n as input
2. Return the factorial of n (n!)
3. Return 1 when n is 0 (0! = 1 by mathematical convention)
4. Return 1 when n is 1 (1! = 1)
5. The result must be an exact integer (no floating-point approximation)

### Input Specification

- **n**: A non-negative integer (0 or greater)
- **Return**: A positive integer representing n!

### Constraints

- Input range: 0 to 20 (to stay within standard 64-bit integer bounds)
- No negative input will be given
- No external math libraries allowed
- Time complexity: O(n)

## Examples

### Example 1: Standard case

**Input**: 5
**Output**: 120
**Explanation**: 5! = 5 × 4 × 3 × 2 × 1 = 120

### Example 2: Zero

**Input**: 0
**Output**: 1
**Explanation**: 0! is defined as 1 by mathematical convention

### Example 3: One

**Input**: 1
**Output**: 1
**Explanation**: 1! = 1

### Example 4: Small value

**Input**: 3
**Output**: 6
**Explanation**: 3! = 3 × 2 × 1 = 6

### Example 5: Larger value

**Input**: 10
**Output**: 3628800
**Explanation**: 10! = 3628800

## Test Cases

### Required Coverage

- n = 0 (base case: 0! = 1)
- n = 1 (base case: 1! = 1)
- n = 2 (smallest non-trivial case)
- Small n (3, 4, or 5)
- Larger n (10 or higher)
- Verify exact integer result (no floating-point rounding)

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] Returns 1 for n = 0
- [ ] Returns 1 for n = 1
- [ ] Returns correct product for all n up to at least 10
- [ ] Returns an exact integer result with no rounding

## Notes

Common mistakes:
- Starting the product accumulator at 0 instead of 1 (yields 0 for all inputs)
- Using 1-based loop start but forgetting the n = 0 base case
- Using floating-point arithmetic (introduces rounding errors for large n)
- Returning n * factorial(n) without a proper base case in recursive implementations (infinite recursion for n = 0)
