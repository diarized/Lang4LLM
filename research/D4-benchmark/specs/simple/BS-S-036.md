# BS-S-036: Check File Exists

**Tier**: Simple
**Category**: File I/O
**Estimated LOC**: 5-10

## Task Description

Given a file path as a string, determine whether a file exists at that path on the filesystem and return a boolean result.

## Requirements

### Functional Requirements

1. Accept a file path string as input
2. Check whether a file exists at that path
3. Return true if the file exists, false if it does not
4. Do not open or read the file contents

### Input Specification

- **file_path**: A string representing a filesystem path (absolute or relative)
- **Return**: A boolean value (true if the file exists, false otherwise)

### Constraints

- The path may be absolute or relative
- An empty string path returns false
- A path that points to a directory (not a file) may return false (check for regular file)
- No read or write operations on the file are required
- Use standard filesystem query functionality

## Examples

### Example 1: Existing file

**Input**: "/tmp/existing_file.txt" (a file that exists on disk)
**Output**: true
**Explanation**: The file is present at the given path

### Example 2: Non-existing file

**Input**: "/tmp/no_such_file.txt" (no file at this path)
**Output**: false
**Explanation**: No file exists at the given path

### Example 3: Empty string

**Input**: ""
**Output**: false
**Explanation**: Empty path cannot correspond to a file

### Example 4: Path to directory

**Input**: "/tmp" (a directory, not a file)
**Output**: false
**Explanation**: Directories are not files; function checks for regular files

### Example 5: Path with subdirectories

**Input**: "/home/user/docs/report.txt" (file exists)
**Output**: true
**Explanation**: Full path with nested directories, file present

## Test Cases

### Required Coverage

- Path to an existing file (returns true)
- Path to a non-existing file (returns false)
- Empty string path
- Path to a directory (not a regular file)
- Relative path to existing file
- Relative path to non-existing file

### Minimum Test Count

6 test cases

## Success Criteria

- [ ] Returns true when file exists at the given path
- [ ] Returns false when no file exists at the given path
- [ ] Returns false for empty string input
- [ ] Returns false for paths that point to directories
- [ ] Does not open or modify the file

## Notes

Common mistakes:
- Returning true for directory paths (not distinguishing files from directories)
- Raising an exception instead of returning false for missing files
- Not handling empty string input
