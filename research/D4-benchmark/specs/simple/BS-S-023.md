# BS-S-023: Remove Leading and Trailing Whitespace

**Tier**: Simple
**Category**: String Processing
**Estimated LOC**: 5-10

## Task Description

Remove all whitespace characters from the beginning and end of a string, returning the trimmed result. Characters in the interior of the string are not modified.

## Requirements

### Functional Requirements

1. Accept a string as input
2. Remove all leading whitespace (spaces, tabs, newlines) from the start
3. Remove all trailing whitespace (spaces, tabs, newlines) from the end
4. Leave interior characters unchanged
5. Return the trimmed string

### Input Specification

- **text**: A string (may contain any characters)
- **Return**: A string with leading and trailing whitespace removed

### Constraints

- Input length: 0 to 100,000 characters
- Whitespace includes space (U+0020), tab (U+0009), and newline characters (U+000A, U+000D)
- If string is entirely whitespace, return an empty string
- Do not remove interior whitespace
- No external libraries required

## Examples

### Example 1: Leading and trailing spaces

**Input**: "  hello  "
**Output**: "hello"
**Explanation**: Both leading and trailing spaces removed

### Example 2: Leading spaces only

**Input**: "   hello"
**Output**: "hello"
**Explanation**: Only leading spaces removed; nothing to remove at end

### Example 3: Trailing spaces only

**Input**: "hello   "
**Output**: "hello"
**Explanation**: Only trailing spaces removed; nothing to remove at start

### Example 4: Interior whitespace preserved

**Input**: "  hello world  "
**Output**: "hello world"
**Explanation**: Interior space between words is not removed

### Example 5: No whitespace

**Input**: "hello"
**Output**: "hello"
**Explanation**: No changes needed

### Example 6: All whitespace

**Input**: "   "
**Output**: ""
**Explanation**: Entire string is whitespace, result is empty string

### Example 7: Empty string

**Input**: ""
**Output**: ""
**Explanation**: Empty string stays empty

## Test Cases

### Required Coverage

- Leading and trailing spaces
- Leading spaces only
- Trailing spaces only
- Interior whitespace preserved
- No whitespace to remove
- Entirely whitespace string
- Empty string
- Tabs and newlines as whitespace

### Minimum Test Count

8 test cases

## Success Criteria

- [ ] Removes all leading whitespace
- [ ] Removes all trailing whitespace
- [ ] Preserves interior characters including interior whitespace
- [ ] Returns empty string when input is entirely whitespace
- [ ] Handles empty input

## Notes

Common mistakes:
- Removing only a single leading or trailing space instead of all of them
- Also stripping interior whitespace
- Treating only space (not tab/newline) as whitespace
