# BS-S-013: Linear Search

**Tier**: Simple
**Category**: Algorithms
**Estimated LOC**: 5-15

## Task Description

Find the index of the first occurrence of a target value in an unsorted list of integers, returning -1 if the target is not present.

## Requirements

### Functional Requirements

1. Accept a list of integers and a target value as input
2. Scan the list from left to right
3. Return the 0-based index of the first occurrence of the target
4. Return -1 if the target does not appear in the list
5. Return -1 if the list is empty

### Input Specification

- **numbers**: A list of integers (may be empty, not necessarily sorted)
- **target**: An integer value to search for
- **Return**: A non-negative integer index if found, or -1 if not found

### Constraints

- List length: 0 to 10,000 elements
- Elements can be any valid integer (positive, negative, zero)
- The list may contain duplicate values; return the index of the first match only
- No built-in search functions or sorted-list assumptions allowed
- Time complexity: O(n) worst case

## Examples

### Example 1: Target found once

**Input**: numbers = [4, 7, 2, 9, 1], target = 9
**Output**: 3
**Explanation**: 9 is at index 3 (0-based)

### Example 2: Target not found

**Input**: numbers = [1, 2, 3, 4, 5], target = 6
**Output**: -1
**Explanation**: 6 is not present in the list

### Example 3: Target appears multiple times

**Input**: numbers = [3, 1, 4, 1, 5, 9], target = 1
**Output**: 1
**Explanation**: 1 first appears at index 1; the later occurrence at index 3 is ignored

### Example 4: Target at first position

**Input**: numbers = [8, 2, 5, 3], target = 8
**Output**: 0
**Explanation**: 8 is found at index 0

### Example 5: Empty list

**Input**: numbers = [], target = 7
**Output**: -1
**Explanation**: No elements to search; target cannot be present

## Test Cases

### Required Coverage

- Target found at beginning (index 0)
- Target found at end (last index)
- Target found in the middle
- Target appears multiple times (return first index)
- Target not in list
- Empty list
- Single element list (found)
- Single element list (not found)

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] Returns correct 0-based index when target is found
- [ ] Returns -1 when target is absent
- [ ] Returns the first index when target appears multiple times
- [ ] Returns -1 for an empty list
- [ ] Does not modify the input list

## Notes

Common mistakes:
- Returning 1-based index instead of 0-based index
- Returning the last occurrence instead of the first
- Not handling the empty list case
- Returning false/null instead of -1 for the not-found case
