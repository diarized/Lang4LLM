# BS-S-021: Capitalize First Letter

**Tier**: Simple
**Category**: String Processing
**Estimated LOC**: 5-10

## Task Description

Transform a string so that the first character is uppercase and all remaining characters are lowercase.

## Requirements

### Functional Requirements

1. Accept a string as input
2. Convert the first character to uppercase
3. Convert all remaining characters to lowercase
4. Return the transformed string

### Input Specification

- **text**: A string of any length (may contain letters, numbers, spaces, punctuation)
- **Return**: A string with the first character uppercased and the rest lowercased

### Constraints

- Input length: 0 to 10,000 characters
- If the string is empty, return an empty string
- If the first character is not a letter, leave it unchanged and lowercase the rest
- No external libraries required

## Examples

### Example 1: All lowercase input

**Input**: "hello"
**Output**: "Hello"
**Explanation**: First character 'h' becomes 'H', remaining letters stay lowercase

### Example 2: All uppercase input

**Input**: "WORLD"
**Output**: "World"
**Explanation**: First character 'W' stays uppercase, remaining 'ORLD' become 'orld'

### Example 3: Mixed case input

**Input**: "hELLO wORLD"
**Output**: "Hello world"
**Explanation**: First 'h' becomes 'H', all remaining characters lowercased

### Example 4: Empty string

**Input**: ""
**Output**: ""
**Explanation**: Empty string returns empty string

### Example 5: Single character

**Input**: "a"
**Output**: "A"
**Explanation**: Single character is uppercased

### Example 6: Starts with non-letter

**Input**: "123abc"
**Output**: "123abc"
**Explanation**: '1' is not a letter, unchanged; 'abc' already lowercase

## Test Cases

### Required Coverage

- All lowercase string
- All uppercase string
- Mixed case string
- Empty string
- Single character
- String starting with a digit or punctuation
- String with only non-letter characters

### Minimum Test Count

7 test cases

## Success Criteria

- [ ] First character is uppercased
- [ ] All remaining characters are lowercased
- [ ] Empty string returns empty string
- [ ] Non-letter first character is left unchanged
- [ ] Returns a new string (original unmodified if applicable)

## Notes

Common mistakes:
- Forgetting to lowercase the remainder of the string (not just capitalizing the first letter)
- Not handling empty string (accessing index 0 on empty string causes error)
- Assuming the first character is always a letter
