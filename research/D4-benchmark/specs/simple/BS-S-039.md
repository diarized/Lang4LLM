# BS-S-039: Find Index of First Occurrence

**Tier**: Simple
**Category**: Miscellaneous
**Estimated LOC**: 10-15

## Task Description

Search a list for the first occurrence of a target value and return its zero-based index. If the target is not present in the list, return -1.

## Requirements

### Functional Requirements

1. Accept a list of values and a target value as inputs
2. Scan the list from left to right (index 0 onward)
3. Return the zero-based index of the first element equal to the target
4. If the target does not appear in the list, return -1
5. Do not use built-in index-finding functions

### Input Specification

- **items**: A list of comparable values (all elements are of the same type)
- **target**: A value of the same type to search for
- **Return**: An integer — the 0-based index of the first match, or -1 if not found

### Constraints

- List length: 0 to 100,000 elements
- Elements can be integers or strings (the comparison uses equality)
- If the list is empty, return -1
- If the target appears multiple times, return the index of the first occurrence only
- Do not use built-in find/index/search functions
- Time complexity: O(n)

## Examples

### Example 1: Target found at start

**Input**: items = [3, 1, 4, 1, 5], target = 3
**Output**: 0
**Explanation**: 3 is at index 0, the first position

### Example 2: Target found in middle

**Input**: items = [3, 1, 4, 1, 5], target = 4
**Output**: 2
**Explanation**: 4 is at index 2

### Example 3: Target not found

**Input**: items = [3, 1, 4, 1, 5], target = 7
**Output**: -1
**Explanation**: 7 does not appear in the list

### Example 4: Duplicate target — first occurrence

**Input**: items = [3, 1, 4, 1, 5], target = 1
**Output**: 1
**Explanation**: 1 appears at indexes 1 and 3; first occurrence is index 1

### Example 5: Empty list

**Input**: items = [], target = 5
**Output**: -1
**Explanation**: No elements to search

### Example 6: Single element, found

**Input**: items = [42], target = 42
**Output**: 0
**Explanation**: Only element matches, index is 0

### Example 7: Single element, not found

**Input**: items = [42], target = 7
**Output**: -1
**Explanation**: Only element does not match

## Test Cases

### Required Coverage

- Target at index 0
- Target in the middle
- Target at the last index
- Target not in list
- Duplicate target (return first occurrence)
- Empty list
- Single-element list (found)
- Single-element list (not found)

### Minimum Test Count

8 test cases

## Success Criteria

- [ ] Returns correct 0-based index when target is found
- [ ] Returns -1 when target is not found
- [ ] Returns index of first occurrence when duplicates exist
- [ ] Handles empty list
- [ ] Does not use built-in index/find functions

## Notes

Common mistakes:
- Returning 1-based index instead of 0-based
- Returning the last occurrence instead of the first (e.g., searching in reverse)
- Returning null or undefined instead of -1 when not found
- Not handling the empty list (may cause out-of-bounds error)
