# BS-S-024: Check if String is Numeric

**Tier**: Simple
**Category**: String Processing
**Estimated LOC**: 10-15

## Task Description

Determine whether a string represents a valid integer, meaning the string consists entirely of an optional leading minus sign followed by one or more digit characters.

## Requirements

### Functional Requirements

1. Accept a string as input
2. Return true if the string represents a valid integer
3. Return false otherwise
4. Allow an optional leading minus sign for negative integers
5. Do not allow leading plus signs, decimal points, spaces, or other non-digit characters

### Input Specification

- **text**: A string of any characters
- **Return**: A boolean value (true if the string is a valid integer representation, false otherwise)

### Constraints

- Valid format: optional single leading '-', followed by one or more digit characters (0-9)
- A string of only '-' is not valid
- An empty string is not valid
- No leading zeros are not disqualified (e.g., "007" is considered valid)
- No external libraries or parsing functions required

## Examples

### Example 1: Positive integer

**Input**: "123"
**Output**: true
**Explanation**: All digit characters, valid integer

### Example 2: Negative integer

**Input**: "-456"
**Output**: true
**Explanation**: Starts with '-' followed by digits, valid negative integer

### Example 3: Contains letters

**Input**: "12a3"
**Output**: false
**Explanation**: 'a' is not a digit character

### Example 4: Empty string

**Input**: ""
**Output**: false
**Explanation**: Empty string is not a valid integer

### Example 5: Minus sign only

**Input**: "-"
**Output**: false
**Explanation**: No digits after the minus sign

### Example 6: Leading spaces

**Input**: " 123"
**Output**: false
**Explanation**: Space is not a valid character

### Example 7: Decimal number

**Input**: "3.14"
**Output**: false
**Explanation**: Decimal point is not allowed for integer check

## Test Cases

### Required Coverage

- Valid positive integer
- Valid negative integer
- String containing letters
- Empty string
- Minus sign only
- String with leading space
- Decimal number
- Zero ("0")
- Leading zeros ("007")
- Plus sign ("+5") — not valid per spec

### Minimum Test Count

10 test cases

## Success Criteria

- [ ] Returns true for valid positive integers
- [ ] Returns true for valid negative integers (leading minus)
- [ ] Returns false for strings containing non-digit characters
- [ ] Returns false for empty string
- [ ] Returns false for bare minus sign
- [ ] Returns false for strings with spaces or decimal points

## Notes

Common mistakes:
- Using a language built-in number parser (which may accept formats this spec disallows, e.g., "+5" or "1e3")
- Forgetting to handle the empty string
- Treating a lone '-' as valid
