# BS-S-027: Absolute Value

**Tier**: Simple
**Category**: Mathematics
**Estimated LOC**: 5-10

## Task Description

Return the absolute value of a given integer without using any built-in absolute value function or library.

## Requirements

### Functional Requirements

1. Accept a single integer as input
2. If the integer is negative, return its positive equivalent
3. If the integer is zero or positive, return it unchanged
4. Do not use any built-in absolute value function (e.g., abs, Math.abs)

### Input Specification

- **number**: An integer (positive, negative, or zero)
- **Return**: A non-negative integer equal to the distance of the input from zero

### Constraints

- Input range: any valid integer within the language's standard integer range
- Do not use built-in abs or equivalent functions
- Solution must be constant time O(1)
- No external libraries required

## Examples

### Example 1: Negative number

**Input**: -7
**Output**: 7
**Explanation**: -7 is 7 units from zero, so absolute value is 7

### Example 2: Positive number

**Input**: 5
**Output**: 5
**Explanation**: Positive number is unchanged

### Example 3: Zero

**Input**: 0
**Output**: 0
**Explanation**: Zero has absolute value 0

### Example 4: Large negative number

**Input**: -1000
**Output**: 1000
**Explanation**: -1000 negated is 1000

### Example 5: Negative one

**Input**: -1
**Output**: 1
**Explanation**: -1 negated is 1

- [ ] Returns positive numbers unchanged

## Notes

The straightforward approach uses a conditional: if the number is less than zero, negate it; otherwise return it as-is. The negation of an integer n is -n or (0 - n).
