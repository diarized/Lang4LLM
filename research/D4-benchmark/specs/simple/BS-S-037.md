# BS-S-037: FizzBuzz

**Tier**: Simple
**Category**: Miscellaneous
**Estimated LOC**: 10-15

## Task Description

Given a positive integer n, produce a list of n strings following the FizzBuzz rules: for each integer from 1 to n inclusive, output "FizzBuzz" if divisible by both 3 and 5, "Fizz" if divisible only by 3, "Buzz" if divisible only by 5, and the integer as a string otherwise.

## Requirements

### Functional Requirements

1. Accept a positive integer n as input
2. For each integer i from 1 to n inclusive:
   - If i is divisible by both 3 and 5, add "FizzBuzz" to the result
   - If i is divisible by 3 only, add "Fizz" to the result
   - If i is divisible by 5 only, add "Buzz" to the result
   - Otherwise, add the string representation of i to the result
3. Return the list of n strings in order

### Input Specification

- **n**: A positive integer (1 or greater) specifying the upper bound of the sequence
- **Return**: A list of n strings following the FizzBuzz rules

### Constraints

- Input range: 1 to 10,000
- The sequence always starts at 1
- Divisibility check: divisible by both 3 and 5 must be checked before checking either individually
- Numbers are represented as strings in the output (not integers)
- Time complexity: O(n)

## Examples

### Example 1: First 15 numbers

**Input**: 15
**Output**: ["1", "2", "Fizz", "4", "Buzz", "Fizz", "7", "8", "Fizz", "Buzz", "11", "Fizz", "13", "14", "FizzBuzz"]
**Explanation**: 3→Fizz, 5→Buzz, 6→Fizz, 9→Fizz, 10→Buzz, 12→Fizz, 15→FizzBuzz

### Example 2: n equals 1

**Input**: 1
**Output**: ["1"]
**Explanation**: Only one element; 1 is not divisible by 3 or 5

### Example 3: n equals 5

**Input**: 5
**Output**: ["1", "2", "Fizz", "4", "Buzz"]
**Explanation**: 3→Fizz, 5→Buzz

### Example 4: n equals 3

**Input**: 3
**Output**: ["1", "2", "Fizz"]
**Explanation**: Only 3 triggers Fizz within this range

## Test Cases

### Required Coverage

- n = 1 (single element, no Fizz/Buzz)
- n = 3 (first Fizz)
- n = 5 (first Buzz)
- n = 15 (first FizzBuzz, full pattern)
- n = 16 (element after FizzBuzz is plain number)
- Verify position 15 is "FizzBuzz"
- Verify position 30 is "FizzBuzz"
- Large n (e.g., 100)

### Minimum Test Count

8 test cases

## Success Criteria

- [ ] "FizzBuzz" appears at all multiples of 15
- [ ] "Fizz" appears at multiples of 3 that are not multiples of 5
- [ ] "Buzz" appears at multiples of 5 that are not multiples of 3
- [ ] All other positions contain the integer as a string
- [ ] List length equals n
- [ ] Sequence starts at 1

## Notes

The most common mistake is checking divisibility by 3 and 5 separately before checking for both. The "FizzBuzz" condition (divisible by both) must be evaluated first to avoid outputting "Fizz" or "Buzz" when "FizzBuzz" is correct.
