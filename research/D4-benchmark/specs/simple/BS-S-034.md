# BS-S-034: Write List to File

**Tier**: Simple
**Category**: File I/O
**Estimated LOC**: 5-10

## Task Description

Write each element of a list to a text file, placing each element on its own line, and close the file when done. If the file already exists, it should be overwritten.

## Requirements

### Functional Requirements

1. Accept a file path and a list of strings as inputs
2. Open the file at the given path for writing (overwrite if it exists, create if it does not)
3. Write each element of the list as a separate line, followed by a newline character
4. Close the file after all elements are written
5. The function does not return a meaningful value

### Input Specification

- **file_path**: A string representing the path where the file should be written
- **lines**: A list of strings to write (may be empty)
- **Return**: Nothing (the side effect is the written file)

### Constraints

- The file path directory is assumed to exist and be writable
- If the list is empty, create an empty file
- Each element is followed by exactly one newline character
- Elements may contain any printable characters (no embedded newlines in elements)
- File encoding: UTF-8

## Examples

### Example 1: Two-element list

**Input**: file_path = "output.txt", lines = ["hello", "world"]
**File result**: File contains "hello\nworld\n"
**Explanation**: Each element on its own line with a trailing newline

### Example 2: Empty list

**Input**: file_path = "output.txt", lines = []
**File result**: File exists but is empty
**Explanation**: No lines to write, file is created but empty

### Example 3: Single element

**Input**: file_path = "output.txt", lines = ["only line"]
**File result**: File contains "only line\n"
**Explanation**: One line written with newline

### Example 4: Overwrite existing file

**Input**: file_path = "existing.txt" (already contains "old content"), lines = ["new content"]
**File result**: File contains "new content\n"
**Explanation**: Previous content is discarded; file is overwritten

### Example 5: Three elements with varied content

**Input**: file_path = "data.txt", lines = ["apple", "banana", "cherry"]
**File result**: File contains "apple\nbanana\ncherry\n"
**Explanation**: Each fruit on its own line

## Test Cases

### Required Coverage

- Normal list with multiple elements
- Empty list (creates empty file)
- Single-element list
- Overwriting an existing file
- List with elements containing spaces
- Verifying newline after each element

### Minimum Test Count

6 test cases

## Success Criteria

- [ ] Each list element appears on its own line in the file
- [ ] Each line is followed by exactly one newline character
- [ ] Empty list results in an empty file
- [ ] Existing file content is overwritten, not appended
- [ ] File is properly closed after writing

## Notes

Common mistakes:
- Appending to the file instead of overwriting
- Forgetting to add a newline after each element
- Adding an extra blank line at the end (double newlines)
- Not closing the file (which may prevent all data from being flushed to disk)
