# BS-S-020: Check Balanced Digits

**Tier**: Simple
**Category**: Algorithms
**Estimated LOC**: 10-15

## Task Description

Determine whether the digits of a non-negative integer are "balanced": the sum of the digits in the first half equals the sum of the digits in the second half. A number with an odd number of digits ignores the middle digit.

## Requirements

### Functional Requirements

1. Accept a non-negative integer as input
2. Extract the sequence of decimal digits of the integer
3. Split the digit sequence into a first half and a second half
4. If the digit count is odd, exclude the middle digit from both halves
5. Return true if the sum of the first-half digits equals the sum of the second-half digits, false otherwise
6. A single-digit number is always considered balanced (both halves are empty, sums are 0 = 0)

### Input Specification

- **n**: A non-negative integer (zero or greater)
- **Return**: A boolean value (true if balanced, false otherwise)

### Constraints

- Input range: 0 to any non-negative integer that fits in a standard 64-bit integer
- Leading zeros in extracted digits are not considered (treat input as its standard decimal representation)
- The number 0 has a single digit (0) and is balanced
- Time complexity: O(d) where d is the number of digits

## Examples

### Example 1: Balanced even-digit number

**Input**: 1230
**Output**: true
**Explanation**: Digits are [1, 2, 3, 0]; first half [1, 2] sums to 3; second half [3, 0] sums to 3; 3 == 3

### Example 2: Unbalanced even-digit number

**Input**: 1231
**Output**: false
**Explanation**: Digits are [1, 2, 3, 1]; first half [1, 2] sums to 3; second half [3, 1] sums to 4; 3 != 4

### Example 3: Odd number of digits (middle ignored)

**Input**: 12321
**Output**: true
**Explanation**: Digits are [1, 2, 3, 2, 1]; middle digit 3 is ignored; first half [1, 2] sums to 3; second half [2, 1] sums to 3; 3 == 3

### Example 4: Single digit

**Input**: 7
**Output**: true
**Explanation**: One digit means both halves are empty; 0 == 0

### Example 5: Zero

**Input**: 0
**Output**: true
**Explanation**: Digit sequence is [0]; single digit, both halves empty; 0 == 0

### Example 6: Two-digit unbalanced

**Input**: 13
**Output**: false
**Explanation**: Digits are [1, 3]; first half [1] sums to 1; second half [3] sums to 3; 1 != 3

## Test Cases

### Required Coverage

- Even digit count, balanced
- Even digit count, unbalanced
- Odd digit count, balanced (middle digit excluded)
- Odd digit count, unbalanced
- Single digit (always balanced)
- n = 0
- Two-digit number

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] Returns true when first-half digit sum equals second-half digit sum
- [ ] Returns false when sums differ
- [ ] Correctly excludes the middle digit for odd-length digit sequences
- [ ] Returns true for single-digit inputs (including 0)

## Notes

Common mistakes:
- Including the middle digit in one or both halves for odd-length numbers
- Computing digit count incorrectly (e.g., treating 0 as having no digits)
- Off-by-one errors when partitioning the digit list into halves
- Forgetting to convert the integer to its digit sequence before splitting
