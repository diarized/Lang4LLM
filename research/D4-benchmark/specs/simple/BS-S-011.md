# BS-S-011: Check if List Contains Element

**Tier**: Simple
**Category**: Data Structures
**Estimated LOC**: 5-10

## Task Description

Determine whether a specific integer value is present anywhere in a list of integers and return a boolean result.

## Requirements

### Functional Requirements

1. Accept a list of integers and a target value as input
2. Return true if the target appears at least once in the list, false otherwise
3. Return false if the list is empty
4. Stop searching as soon as the target is found (early exit)

### Input Specification

- **numbers**: A list of integers (may be empty)
- **target**: An integer value to search for
- **Return**: A boolean value (true if target is found, false otherwise)

### Constraints

- List length: 0 to 10,000 elements
- Target and list elements can be any valid integer (positive, negative, zero)
- No built-in contains/in/includes functions allowed
- Time complexity: O(n) worst case
- Space complexity: O(1)

## Examples

### Example 1: Target found in the middle

**Input**: numbers = [10, 20, 30, 40], target = 30
**Output**: true
**Explanation**: 30 is present at index 2

### Example 2: Target not in list

**Input**: numbers = [1, 2, 3, 4], target = 9
**Output**: false
**Explanation**: 9 does not appear anywhere in the list

### Example 3: Empty list

**Input**: numbers = [], target = 5
**Output**: false
**Explanation**: An empty list contains no elements, so the target cannot be found

### Example 4: Target is the first element

**Input**: numbers = [7, 1, 2, 3], target = 7
**Output**: true
**Explanation**: 7 is found immediately at index 0

### Example 5: Target is zero

**Input**: numbers = [-1, 0, 1], target = 0
**Output**: true
**Explanation**: Zero is a valid element and is present in the list

## Test Cases

### Required Coverage

- Target found at beginning of list
- Target found at end of list
- Target found in the middle of list
- Target not present in list
- Empty list
- List with one element (found)
- List with one element (not found)
- Target is zero or negative

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] Returns true when target is present anywhere in the list
- [ ] Returns false when target is absent
- [ ] Returns false for an empty list
- [ ] Does not modify the input list

## Notes

Common mistakes:
- Returning the index instead of a boolean
- Forgetting to handle the empty list (some languages raise errors on empty iteration)
- Not returning early once the target is found (functionally correct but inefficient)
