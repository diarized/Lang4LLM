# BS-S-018: Move Zeros to End

**Tier**: Simple
**Category**: Algorithms
**Estimated LOC**: 10-15

## Task Description

Rearrange a list of integers so that all zero values are moved to the end of the list, while the relative order of all non-zero elements is preserved.

## Requirements

### Functional Requirements

1. Accept a list of integers as input
2. Return a new list where all non-zero elements appear first, in their original relative order
3. All zero values appear at the end of the returned list, in any order
4. The count of each value (including zeros) must be the same in the output as in the input
5. The original list must not be modified

### Input Specification

- **numbers**: A list of integers (may be empty, may contain zeros)
- **Return**: A list of integers with non-zero elements first (original order) followed by all zeros

### Constraints

- List length: 0 to 10,000 elements
- Elements can be any valid integer (positive, negative, zero)
- The relative order of non-zero elements must be preserved
- Time complexity: O(n)

## Examples

### Example 1: Standard case

**Input**: [0, 1, 0, 3, 12]
**Output**: [1, 3, 12, 0, 0]
**Explanation**: Non-zeros (1, 3, 12) keep their relative order; zeros are moved to the end

### Example 2: No zeros

**Input**: [1, 2, 3]
**Output**: [1, 2, 3]
**Explanation**: No zeros to move; output equals input

### Example 3: All zeros

**Input**: [0, 0, 0]
**Output**: [0, 0, 0]
**Explanation**: All elements are zero; output is the same

### Example 4: Zero at the end already

**Input**: [5, 6, 0]
**Output**: [5, 6, 0]
**Explanation**: Zero is already at the end; no change needed

### Example 5: Negative numbers and zeros

**Input**: [0, -3, 0, 5, -1, 0]
**Output**: [-3, 5, -1, 0, 0, 0]
**Explanation**: Non-zeros (-3, 5, -1) are kept in order; three zeros go to the end

## Test Cases

### Required Coverage

- Mixed list with zeros interspersed
- List with no zeros
- List with all zeros
- Zero already at the end
- Zeros at the beginning
- List with negative numbers and zeros
- Empty list
- Single element zero
- Single non-zero element

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] All non-zero elements appear before all zeros in the output
- [ ] Non-zero elements preserve their original relative order
- [ ] Total element count and zero count are unchanged
- [ ] Handles all-zero and no-zero lists correctly
- [ ] Does not modify the original input list

## Notes

Common mistakes:
- Destroying the relative order of non-zero elements
- Changing the count of zeros (dropping or adding zeros)
- Treating negative numbers as zeros
- Modifying the input list in place when a new list is expected
