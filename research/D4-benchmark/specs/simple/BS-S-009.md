# BS-S-009: Count Occurrences of Element

**Tier**: Simple
**Category**: Data Structures
**Estimated LOC**: 5-10

## Task Description

Count how many times a specific value appears in a list of integers and return that count.

## Requirements

### Functional Requirements

1. Accept a list of integers and a target value as input
2. Return the number of times the target value appears in the list
3. Return 0 if the target does not appear at all
4. Return 0 if the list is empty

### Input Specification

- **numbers**: A list of integers (may be empty)
- **target**: An integer value to search for
- **Return**: A non-negative integer representing the count of occurrences

### Constraints

- List length: 0 to 10,000 elements
- Target and list elements can be any valid integer (positive, negative, zero)
- No built-in count() functions allowed
- Time complexity: O(n) where n is list length
- Space complexity: O(1)

## Examples

### Example 1: Target appears multiple times

**Input**: numbers = [1, 2, 3, 2, 4, 2], target = 2
**Output**: 3
**Explanation**: The value 2 appears at positions 1, 3, and 5 (0-indexed)

### Example 2: Target appears once

**Input**: numbers = [5, 10, 15, 20], target = 15
**Output**: 1
**Explanation**: 15 appears exactly once in the list

### Example 3: Target not present

**Input**: numbers = [1, 2, 3, 4], target = 9
**Output**: 0
**Explanation**: 9 does not appear anywhere in the list

### Example 4: Empty list

**Input**: numbers = [], target = 5
**Output**: 0
**Explanation**: There are no elements in an empty list to match

### Example 5: All elements match target

**Input**: numbers = [3, 3, 3, 3], target = 3
**Output**: 4
**Explanation**: Every element equals the target; all four are counted

## Test Cases

### Required Coverage

- Target appears multiple times
- Target appears exactly once
- Target does not appear at all
- Empty list
- All elements equal the target
- Target is a negative number
- Target is zero

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] Returns correct count for a target that appears multiple times
- [ ] Returns 1 when target appears exactly once
- [ ] Returns 0 when target is absent
- [ ] Returns 0 for an empty list
- [ ] Does not modify the input list

## Notes

Common mistakes:
- Returning a boolean (found/not found) instead of a count
- Off-by-one errors in loop bounds
- Using a built-in count method when the goal is to practice manual iteration
