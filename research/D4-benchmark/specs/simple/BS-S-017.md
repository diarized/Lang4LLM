# BS-S-017: Find Second Maximum

**Tier**: Simple
**Category**: Algorithms
**Estimated LOC**: 10-15

## Task Description

Return the second largest distinct value in a list of integers. If the list does not contain at least two distinct values, return null/none to signal that no second maximum exists.

## Requirements

### Functional Requirements

1. Accept a list of integers as input
2. Find the largest distinct value (first maximum) in the list
3. Find the largest distinct value that is strictly less than the first maximum (second maximum)
4. Return the second maximum as an integer
5. Return null/none if fewer than two distinct values exist in the list (includes empty lists and all-same-element lists)

### Input Specification

- **numbers**: A list of integers (may be empty or contain duplicates)
- **Return**: An integer representing the second distinct maximum, or null/none if no such value exists

### Constraints

- List length: 0 to 10,000 elements
- Elements can be any valid integer (positive, negative, zero)
- Duplicates of the maximum value do not count as a second maximum
- Time complexity: O(n) preferred (single or two-pass scan)

## Examples

### Example 1: Clear second maximum

**Input**: [3, 1, 4, 1, 5, 9, 2, 6]
**Output**: 6
**Explanation**: The maximum is 9; the second distinct maximum is 6

### Example 2: All elements equal

**Input**: [5, 5, 5]
**Output**: null/none
**Explanation**: There is only one distinct value, so no second maximum exists

### Example 3: Two distinct values

**Input**: [4, 4, 7, 7]
**Output**: 4
**Explanation**: The maximum is 7; the second distinct maximum is 4

### Example 4: Single element

**Input**: [10]
**Output**: null/none
**Explanation**: Only one element; no second maximum is possible

### Example 5: Negative numbers

**Input**: [-1, -5, -3]
**Output**: -3
**Explanation**: Maximum is -1; the second distinct maximum is -3

## Test Cases

### Required Coverage

- List with several distinct values (standard case)
- List where maximum appears multiple times (second max is still the next distinct value)
- All elements equal (no second max)
- Single element list
- Empty list
- Two distinct values
- List with negative numbers only
- List with mixed positive and negative values

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] Returns the correct second distinct maximum
- [ ] Treats duplicate maximums correctly (does not accept a duplicate of the max as second max)
- [ ] Returns null/none when fewer than two distinct values exist
- [ ] Handles negative numbers correctly
- [ ] Does not modify the input list

## Notes

Common mistakes:
- Treating a duplicate of the maximum as the second maximum
- Sorting the list and picking the second-to-last element (fails to account for duplicates)
- Not handling the case where no second maximum exists (throwing an exception instead of returning null/none)
- Using a two-variable tracking approach but not updating correctly when equal values are encountered
