# BS-S-022: Count Words in String

**Tier**: Simple
**Category**: String Processing
**Estimated LOC**: 5-10

## Task Description

Count the number of words in a string, where words are defined as contiguous sequences of non-whitespace characters separated by one or more whitespace characters.

## Requirements

### Functional Requirements

1. Accept a string as input
2. Split the string on whitespace boundaries
3. Count the resulting word tokens
4. Return the total word count

### Input Specification

- **text**: A string (may contain letters, numbers, punctuation, spaces, tabs, newlines)
- **Return**: A non-negative integer representing the number of whitespace-separated words

### Constraints

- Input length: 0 to 100,000 characters
- Multiple consecutive whitespace characters count as a single separator
- Leading and trailing whitespace does not produce empty words
- An empty string or whitespace-only string has 0 words
- Time complexity: O(n)

## Examples

### Example 1: Simple sentence

**Input**: "hello world"
**Output**: 2
**Explanation**: Two whitespace-separated tokens: "hello" and "world"

### Example 2: Multiple spaces between words

**Input**: "hello   world"
**Output**: 2
**Explanation**: Multiple spaces count as one separator; still 2 words

### Example 3: Leading and trailing whitespace

**Input**: "  hello world  "
**Output**: 2
**Explanation**: Leading/trailing whitespace does not produce empty words

### Example 4: Empty string

**Input**: ""
**Output**: 0
**Explanation**: No characters, no words

### Example 5: Single word

**Input**: "hello"
**Output**: 1
**Explanation**: One token with no separators

### Example 6: Whitespace only

**Input**: "   "
**Output**: 0
**Explanation**: No non-whitespace tokens

## Test Cases

### Required Coverage

- Simple multi-word string
- Multiple consecutive spaces between words
- Leading whitespace
- Trailing whitespace
- Empty string
- Single word
- Whitespace-only string
- String with tabs or newlines as separators

### Minimum Test Count

8 test cases

## Success Criteria

- [ ] Correctly counts words separated by single spaces
- [ ] Treats multiple consecutive spaces as one separator
- [ ] Ignores leading and trailing whitespace
- [ ] Returns 0 for empty or whitespace-only strings
- [ ] Handles single-word strings

## Notes

Common mistakes:
- Splitting on single space and counting empty strings as words
- Off-by-one when counting tokens
- Not handling leading/trailing whitespace correctly
