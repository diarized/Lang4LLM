# BS-S-019: Find Missing Number

**Tier**: Simple
**Category**: Algorithms
**Estimated LOC**: 5-15

## Task Description

Given a list of n-1 distinct integers drawn from the range 1 to n (inclusive), find and return the single missing integer from that range.

## Requirements

### Functional Requirements

1. Accept a list of integers as input
2. The list contains exactly n-1 distinct integers, each in the range 1 to n
3. Exactly one integer from 1 to n is absent; find and return it
4. The list may be given in any order (not necessarily sorted)

### Input Specification

- **numbers**: A list of n-1 distinct integers, each between 1 and n inclusive
- **Return**: The single missing integer in the range [1, n], where n = length of the list + 1

### Constraints

- List length: 1 to 9,999 elements (so n ranges from 2 to 10,000)
- All elements in the list are distinct
- All elements are in the range [1, n] where n = list length + 1
- Exactly one integer from [1, n] is missing
- Time complexity: O(n)
- Space complexity: O(1) preferred

## Examples

### Example 1: Missing number in the middle

**Input**: [1, 2, 4, 5]
**Output**: 3
**Explanation**: n = 5 (list has 4 elements); range is 1–5; 3 is absent

### Example 2: Missing number at the start

**Input**: [2, 3, 4]
**Output**: 1
**Explanation**: n = 4; range is 1–4; 1 is absent

### Example 3: Missing number at the end

**Input**: [1, 2, 3]
**Output**: 4
**Explanation**: n = 4; range is 1–4; 4 is absent

### Example 4: Two element range, first missing

**Input**: [2]
**Output**: 1
**Explanation**: n = 2; range is 1–2; 1 is absent

### Example 5: Unsorted list

**Input**: [5, 3, 1, 2]
**Output**: 4
**Explanation**: n = 5; range is 1–5; 4 is absent regardless of input order

## Test Cases

### Required Coverage

- Missing number in the middle of the range
- Missing number is 1 (start of range)
- Missing number is n (end of range)
- Single-element list (n = 2)
- Unsorted input list
- Larger list (10+ elements)

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] Returns the correct missing integer for all positions in the range
- [ ] Works correctly regardless of input order
- [ ] Handles the minimal case (list length 1)
- [ ] Does not modify the input list

## Notes

Common mistakes:
- Sorting the list and looking for the gap (works but unnecessary; O(n log n) time)
- Forgetting that n = list length + 1, not list length
- Using a range sum formula: expected sum = n*(n+1)/2; actual sum = sum of list; missing = expected - actual
- Assuming the list is sorted (robust solution must handle any order)
