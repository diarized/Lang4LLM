# BS-S-028: GCD of Two Numbers

**Tier**: Simple
**Category**: Mathematics
**Estimated LOC**: 10-15

## Task Description

Compute the greatest common divisor (GCD) of two positive integers, which is the largest integer that divides both numbers without a remainder.

## Requirements

### Functional Requirements

1. Accept two positive integers as inputs
2. Compute and return their greatest common divisor
3. Use the Euclidean algorithm (repeated division by remainder)
4. The result is always a positive integer

### Input Specification

- **a**: A positive integer (greater than 0)
- **b**: A positive integer (greater than 0)
- **Return**: A positive integer that is the GCD of a and b

### Constraints

- Input range: 1 to 1,000,000 for each input
- Both inputs are guaranteed to be positive integers
- GCD(a, b) = GCD(b, a) (order does not matter)
- No external libraries required
- Do not use a built-in GCD function

### Euclidean Algorithm

The Euclidean algorithm works as follows:
- While the second number is not zero, replace the pair (a, b) with (b, a mod b)
- When the second number reaches zero, the first number is the GCD

## Examples

### Example 1: Common case

**Input**: a = 48, b = 18
**Output**: 6
**Explanation**: 6 is the largest number dividing both 48 and 18

### Example 2: One divides the other

**Input**: a = 12, b = 4
**Output**: 4
**Explanation**: 4 divides 12 evenly, so GCD is 4

### Example 3: Coprime numbers

**Input**: a = 7, b = 13
**Output**: 1
**Explanation**: 7 and 13 share no common factor other than 1

### Example 4: Same number

**Input**: a = 9, b = 9
**Output**: 9
**Explanation**: GCD of a number with itself is the number

### Example 5: One is 1

**Input**: a = 1, b = 100
**Output**: 1
**Explanation**: 1 divides every integer, so GCD is always 1 when one input is 1

## Test Cases

### Required Coverage

- Two numbers with a non-trivial common factor
- One number divides the other exactly
- Coprime numbers (GCD = 1)
- Both numbers are equal
- One number is 1
- Large numbers with small GCD
- Order reversed (GCD(a, b) = GCD(b, a))

### Minimum Test Count

7 test cases

## Success Criteria

- [ ] Correctly computes GCD for general cases
- [ ] Returns correct result when one number divides the other
- [ ] Returns 1 for coprime inputs
- [ ] Returns the number itself when both inputs are equal
- [ ] Does not use a built-in GCD function

## Notes

Common mistakes:
- Confusing LCM (least common multiple) with GCD
- Infinite loop due to wrong modulo direction
- Not handling the case where either input equals 1
