# BS-S-038: Clamp Value

**Tier**: Simple
**Category**: Miscellaneous
**Estimated LOC**: 5-10

## Task Description

Given a numeric value and a minimum and maximum bound, return the value constrained to the closed interval [min, max]. If the value falls within the range, return it unchanged; if it is below the minimum, return the minimum; if it is above the maximum, return the maximum.

## Requirements

### Functional Requirements

1. Accept three numeric inputs: value, minimum bound, and maximum bound
2. If value < minimum, return minimum
3. If value > maximum, return maximum
4. If minimum <= value <= maximum, return value unchanged
5. The minimum is always less than or equal to the maximum

### Input Specification

- **value**: A numeric value (integer or floating-point) to be clamped
- **min_val**: A numeric value representing the lower bound of the range
- **max_val**: A numeric value representing the upper bound of the range (min_val <= max_val guaranteed)
- **Return**: A numeric value within the closed interval [min_val, max_val]

### Constraints

- min_val <= max_val is always guaranteed by the caller
- All inputs are valid numbers (no NaN or infinity handling required)
- The function works with both integer and floating-point inputs
- No external libraries required
- Solution should be constant time O(1)

## Examples

### Example 1: Value within range

**Input**: value = 5, min_val = 1, max_val = 10
**Output**: 5
**Explanation**: 5 is within [1, 10], returned unchanged

### Example 2: Value below minimum

**Input**: value = -3, min_val = 0, max_val = 100
**Output**: 0
**Explanation**: -3 is below the minimum 0, so return 0

### Example 3: Value above maximum

**Input**: value = 150, min_val = 0, max_val = 100
**Output**: 100
**Explanation**: 150 exceeds the maximum 100, so return 100

### Example 4: Value equals minimum

**Input**: value = 0, min_val = 0, max_val = 10
**Output**: 0
**Explanation**: Value is exactly at the lower bound, returned unchanged

### Example 5: Value equals maximum

**Input**: value = 10, min_val = 0, max_val = 10
**Output**: 10
**Explanation**: Value is exactly at the upper bound, returned unchanged

### Example 6: Floating-point values

**Input**: value = 1.5, min_val = 0.0, max_val = 1.0
**Output**: 1.0
**Explanation**: 1.5 exceeds the floating-point maximum 1.0

## Test Cases

### Required Coverage

- Value within range
- Value below minimum
- Value above maximum
- Value exactly equal to minimum
- Value exactly equal to maximum
- Floating-point inputs
- Negative range (e.g., min=-10, max=-1)

### Minimum Test Count

7 test cases

## Success Criteria

- [ ] Returns value unchanged when within [min, max]
- [ ] Returns min when value is below min
- [ ] Returns max when value is above max
- [ ] Handles boundary values (value == min, value == max) correctly
- [ ] Works with both integer and floating-point inputs

## Notes

Common mistakes:
- Swapping min and max in the comparisons
- Using strict inequality instead of inclusive bounds (should return value when value == min or value == max, not clamp it further)
- Not handling the case where min == max (valid degenerate range; any input should return min == max)
