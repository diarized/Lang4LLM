# BS-S-005: Count Vowels in String

**Tier**: Simple
**Category**: String Processing
**Estimated LOC**: 10-15

## Task Description

Count the number of vowels (a, e, i, o, u) in a given string, case-insensitive.

## Requirements

### Functional Requirements

1. Accept a string as input
2. Count all vowels (a, e, i, o, u) regardless of case
3. Ignore consonants, numbers, and special characters
4. Return the total count

### Input Specification

- **text**: A string (letters, numbers, spaces, punctuation)
- **Return**: An integer count of vowels (0 or greater)

### Constraints

- Input length: 0 to 10,000 characters
- Case-insensitive ('A' and 'a' both count)
- Only English vowels (a, e, i, o, u)
- Time complexity: O(n)

## Examples

### Example 1: Lowercase

**Input**: "hello"
**Output**: 2
**Explanation**: 'e' and 'o' are vowels

### Example 2: Mixed case

**Input**: "Hello World"
**Output**: 3
**Explanation**: 'e', 'o', 'o' are vowels (case doesn't matter)

### Example 3: No vowels

**Input**: "rhythm"
**Output**: 0
**Explanation**: No vowels present

### Example 4: All vowels

**Input**: "aeiou"
**Output**: 5
**Explanation**: All five vowels present

### Example 5: With numbers and punctuation

**Input**: "hello123!!"
**Output**: 2
**Explanation**: Only letters 'e' and 'o' are vowels

### Example 6: Empty string

**Input**: ""
**Output**: 0
**Explanation**: No characters means no vowels

## Test Cases

### Required Coverage

- String with vowels
- String without vowels
- Mixed case string
- String with numbers and punctuation

- String with all vowels
- String with repeated vowels

### Minimum Test Count

7 test cases

## Success Criteria

- [ ] Correctly counts all vowels
- [ ] Case-insensitive counting
- [ ] Ignores non-letter characters
- [ ] Handles empty string
- [ ] O(n) time complexity

## Notes

Common mistakes:
- Not handling case-insensitivity
- Counting 'y' as a vowel (only a, e, i, o, u)
- Not initializing counter to 0
