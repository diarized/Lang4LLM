# BS-S-010: Rotate Array Left

**Tier**: Simple
**Category**: Data Structures
**Estimated LOC**: 10-15

## Task Description

Shift all elements of a list to the left by k positions, wrapping elements that fall off the left end around to the right end, and return the resulting list.

## Requirements

### Functional Requirements

1. Accept a list of integers and a non-negative integer k as input
2. Return a new list where each element has been shifted left by k positions
3. Elements shifted past the beginning wrap around to the end of the list
4. If k is 0 or a multiple of the list length, the output equals the input
5. The original list must not be modified

### Input Specification

- **numbers**: A list of integers (may be empty)
- **k**: A non-negative integer representing the number of positions to rotate left
- **Return**: A list of integers after left rotation by k positions

### Constraints

- List length: 0 to 10,000 elements
- k: 0 or any positive integer (may be larger than the list length; use modular reduction)
- Time complexity: O(n) where n is list length
- Space complexity: O(n) for the output list

## Examples

### Example 1: Basic left rotation

**Input**: numbers = [1, 2, 3, 4, 5], k = 2
**Output**: [3, 4, 5, 1, 2]
**Explanation**: Elements at positions 0 and 1 (values 1, 2) move to the end; the rest shift left

### Example 2: k equals list length

**Input**: numbers = [1, 2, 3], k = 3
**Output**: [1, 2, 3]
**Explanation**: Rotating by the full length returns the original order

### Example 3: k larger than list length

**Input**: numbers = [1, 2, 3, 4], k = 6
**Output**: [3, 4, 1, 2]
**Explanation**: 6 mod 4 = 2, so this is equivalent to a left rotation by 2

### Example 4: k is zero

**Input**: numbers = [7, 8, 9], k = 0
**Output**: [7, 8, 9]
**Explanation**: No rotation is applied; output equals input

### Example 5: Empty list

**Input**: numbers = [], k = 5
**Output**: []
**Explanation**: Rotating an empty list produces an empty list

## Test Cases

### Required Coverage

- Rotation by a small k (less than list length)
- Rotation by k equal to list length (no net change)
- Rotation by k greater than list length (modular reduction)
- k equals zero (no rotation)
- Empty list
- Single element list
- Rotation by k = 1 (one step left)

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] Produces correct rotation for standard k values
- [ ] Handles k equal to or greater than list length via modular reduction
- [ ] Returns unchanged list when k is 0 or a multiple of list length
- [ ] Handles empty and single-element lists without error
- [ ] Does not modify the original input list

## Notes

Common mistakes:
- Forgetting to reduce k modulo the list length (causes index-out-of-bounds errors or incorrect output for large k)
- Rotating right instead of left
- Modifying the input list in place rather than building a new output
- Not handling the empty list case (modulo by zero is undefined)
