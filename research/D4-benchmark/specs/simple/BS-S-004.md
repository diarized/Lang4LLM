# BS-S-004: Sum of List

**Tier**: Simple
**Category**: Data Structures
**Estimated LOC**: 8-12

## Task Description

Calculate the sum of all numbers in a list of integers.

## Requirements

### Functional Requirements

1. Accept a list of integers as input
2. Return the sum of all values
3. Handle negative numbers correctly
4. Return 0 for empty list

### Input Specification

- **numbers**: A list of integers (may be empty)
- **Return**: An integer representing the total sum

### Constraints

- List length: 0 to 10,000 elements
- Numbers may be positive, negative, or zero
- No built-in sum() functions allowed
- Time complexity: O(n)

## Examples

### Example 1: Positive numbers

**Input**: [1, 2, 3, 4, 5]
**Output**: 15
**Explanation**: 1 + 2 + 3 + 4 + 5 = 15

### Example 2: Negative numbers

**Input**: [-1, -2, -3]
**Output**: -6
**Explanation**: (-1) + (-2) + (-3) = -6

### Example 3: Mixed

**Input**: [10, -5, 3, -2]
**Output**: 6
**Explanation**: 10 + (-5) + 3 + (-2) = 6

### Example 4: Empty list

**Input**: []
**Output**: 0
**Explanation**: Sum of no numbers is 0

### Example 5: Single element

**Input**: [42]
**Output**: 42
**Explanation**: Sum of one number is itself

## Test Cases

### Required Coverage

- All negative numbers

- Empty list

6 test cases
