# BS-S-035: Count Lines in File

**Tier**: Simple
**Category**: File I/O
**Estimated LOC**: 5-10

## Task Description

Open a text file at a given path and count the total number of lines it contains, returning that count as an integer.

## Requirements

### Functional Requirements

1. Accept a file path as input
2. Open and read the text file at that path
3. Count the number of lines in the file
4. Return the line count as a non-negative integer

### Input Specification

- **file_path**: A string representing a valid path to an existing text file
- **Return**: A non-negative integer representing the number of lines

### Constraints

- The file is guaranteed to exist and be readable
- File encoding: UTF-8
- An empty file has 0 lines
- A file whose content ends with a newline: the final newline does not count as an additional empty line (e.g., "hello\nworld\n" has 2 lines)
- A file whose content does not end with a newline is still counted correctly (e.g., "hello\nworld" has 2 lines)

### Line Counting Convention

- Count equals the number of newline-terminated or newline-separated text segments with content
- A file containing only a single newline has 1 line (one empty line)
- A blank line in the middle of a file counts as a line

## Examples

### Example 1: Two-line file

**File content**: "hello\nworld\n"
**Output**: 2
**Explanation**: Two lines of text

### Example 2: File without trailing newline

**File content**: "hello\nworld"
**Output**: 2
**Explanation**: Still two lines even without trailing newline

### Example 3: Empty file

**File content**: ""
**Output**: 0
**Explanation**: No lines in an empty file

### Example 4: Single line

**File content**: "only line\n"
**Output**: 1
**Explanation**: One line of text

### Example 5: File with blank line

**File content**: "line1\n\nline3\n"
**Output**: 3
**Explanation**: Three lines: "line1", "" (blank), "line3"

## Test Cases

### Required Coverage

- Multi-line file with trailing newline
- Multi-line file without trailing newline
- Empty file (0 lines)
- Single-line file
- File with blank lines
- Large file (many lines)

### Minimum Test Count

6 test cases

## Success Criteria

- [ ] Returns correct count for multi-line files
- [ ] Returns 0 for empty files
- [ ] Handles files with and without trailing newlines consistently
- [ ] Counts blank lines as lines
- [ ] Does not double-count the final newline

## Notes

The most natural approach is to read all lines (stripping trailing newlines) and count the resulting list, then verify the count is not inflated by a trailing newline. Another approach is to count newline characters in the raw content, adding 1 if the file is non-empty and does not end with a newline.

Common mistakes:
- Counting the empty string produced by a trailing newline as an extra line
- Returning 0 for a single-line file that has no trailing newline
