# BS-S-014: Count Elements Greater Than Threshold

**Tier**: Simple
**Category**: Algorithms
**Estimated LOC**: 5-10

## Task Description

Count how many integers in a list are strictly greater than a given threshold value and return that count.

## Requirements

### Functional Requirements

1. Accept a list of integers and a threshold integer as input
2. Count every element that is strictly greater than the threshold (not equal)
3. Return the count as a non-negative integer
4. Return 0 if the list is empty or no element exceeds the threshold

### Input Specification

- **numbers**: A list of integers (may be empty)
- **threshold**: An integer value used as the comparison boundary
- **Return**: A non-negative integer representing how many elements are strictly greater than the threshold

### Constraints

- List length: 0 to 10,000 elements
- Elements and threshold can be any valid integer (positive, negative, zero)
- Comparison is strict: elements equal to the threshold are not counted
- Time complexity: O(n) where n is list length
- Space complexity: O(1)

## Examples

### Example 1: Several elements exceed threshold

**Input**: numbers = [1, 5, 3, 8, 2, 7], threshold = 4
**Output**: 3
**Explanation**: Values 5, 8, and 7 are strictly greater than 4; the others (1, 3, 2) are not

### Example 2: No elements exceed threshold

**Input**: numbers = [1, 2, 3], threshold = 5
**Output**: 0
**Explanation**: All elements are less than or equal to 5

### Example 3: Element equals threshold (not counted)

**Input**: numbers = [3, 5, 7], threshold = 5
**Output**: 1
**Explanation**: 7 exceeds 5; the element equal to 5 is not counted (strict comparison)

### Example 4: Empty list

**Input**: numbers = [], threshold = 10
**Output**: 0
**Explanation**: No elements to compare

### Example 5: Negative threshold

**Input**: numbers = [-3, -1, 0, 2], threshold = -2
**Output**: 3
**Explanation**: -1, 0, and 2 are all strictly greater than -2; -3 is not

## Test Cases

### Required Coverage

- Multiple elements exceed the threshold
- No elements exceed the threshold
- Element exactly equals threshold (must not be counted)
- Empty list
- Negative threshold
- All elements exceed the threshold
- Threshold larger than all elements

### Minimum Test Count

5 test cases

## Success Criteria

- [ ] Counts only elements strictly greater than the threshold
- [ ] Excludes elements equal to the threshold
- [ ] Returns 0 for an empty list
- [ ] Handles negative numbers and negative thresholds correctly
- [ ] Does not modify the input list

## Notes

Common mistakes:
- Using greater-than-or-equal instead of strict greater-than (overcounts by including equals)
- Returning a boolean instead of a count
- Off-by-one errors in loop bounds
