# BS-S-002: Reverse String

**Tier**: Simple
**Category**: String Processing
**Estimated LOC**: 5-10

## Task Description

Reverse the order of characters in a given string.

## Requirements

### Functional Requirements

1. Accept a string as input
2. Return a new string with characters in reverse order
3. Preserve all characters including spaces and special characters
4. Handle empty strings

### Input Specification

- **text**: A string (may contain letters, numbers, spaces, punctuation)
- **Return**: A string with characters in reverse order

### Constraints

- Input length: 0 to 10,000 characters
- No external string manipulation libraries
- Should work with Unicode characters
- Time complexity: O(n) where n is string length

## Examples

### Example 1: Simple word

**Input**: "hello"
**Output**: "olleh"
**Explanation**: Characters reversed from end to start

### Example 2: With spaces

**Input**: "hello world"
**Output**: "dlrow olleh"
**Explanation**: Spaces are preserved in reversed positions

### Example 3: Palindrome

**Input**: "racecar"
**Output**: "racecar"
**Explanation**: Palindrome reverses to itself

### Example 4: Empty string

**Input**: ""
**Output**: ""
**Explanation**: Empty string reverses to empty string

### Example 5: Single character

**Input**: "a"
**Output**: "a"
**Explanation**: Single character reverses to itself

## Test Cases

### Required Coverage

- Non-empty string
- String with spaces
- String with special characters
- Empty string
- Single character string
- Palindrome

### Minimum Test Count

6 test cases

## Success Criteria

- [ ] Correctly reverses all characters
- [ ] Preserves spaces and punctuation
- [ ] Handles empty string
- [ ] Handles single character

## Notes

Common pitfall: Modifying string in place (some languages require creating new string).
