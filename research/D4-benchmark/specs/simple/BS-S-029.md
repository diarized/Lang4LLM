# BS-S-029: Check Prime Number

**Tier**: Simple
**Category**: Mathematics
**Estimated LOC**: 10-15

## Task Description

Determine whether a given positive integer is a prime number, meaning it has exactly two distinct positive divisors: 1 and itself.

## Requirements

### Functional Requirements

1. Accept a positive integer as input
2. Return true if the number is prime
3. Return false if the number is not prime (composite or 1)
4. A prime number must be greater than 1 and divisible only by 1 and itself

### Input Specification

- **number**: A positive integer (greater than 0)
- **Return**: A boolean value (true if prime, false otherwise)

### Constraints

- Input range: 1 to 1,000,000
- 1 is not prime by definition
- 2 is the smallest prime and the only even prime
- No external libraries or prime-checking functions required
- Aim for O(sqrt(n)) time complexity

## Examples

### Example 1: Small prime

**Input**: 7
**Output**: true
**Explanation**: 7 has no divisors other than 1 and 7

### Example 2: Composite number

**Input**: 9
**Output**: false
**Explanation**: 9 = 3 * 3, so it has divisors other than 1 and 9

### Example 3: Number 1

**Input**: 1
**Output**: false
**Explanation**: By definition, 1 is not prime

### Example 4: Number 2

**Input**: 2
**Output**: true
**Explanation**: 2 is the smallest prime number

### Example 5: Even number greater than 2

**Input**: 4
**Output**: false
**Explanation**: 4 = 2 * 2, not prime

### Example 6: Large prime

**Input**: 97
**Output**: true
**Explanation**: 97 has no divisors between 2 and 96

## Test Cases

### Required Coverage

- Small prime (2, 3, 5, 7)
- Composite number with small factor
- Number 1 (not prime by definition)
- Number 2 (smallest prime)
- Even composite number
- Large prime
- Large composite number
- Number 4 (smallest composite after primes)

### Minimum Test Count

8 test cases

## Success Criteria

- [ ] Returns true for all prime inputs
- [ ] Returns false for composite numbers
- [ ] Returns false for 1
- [ ] Handles 2 correctly (smallest prime)
- [ ] Efficient enough for inputs up to 1,000,000

## Notes

Common mistakes:
- Treating 1 as prime
- Not handling 2 as the only even prime (special-casing evens can simplify the loop)
- Checking divisors up to n instead of sqrt(n), causing unnecessary work
- Off-by-one: divisor loop should check up to and including sqrt(n)
