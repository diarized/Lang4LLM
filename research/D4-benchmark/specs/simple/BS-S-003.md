# BS-S-003: Find Maximum in List

**Tier**: Simple
**Category**: Data Structures
**Estimated LOC**: 10-15

## Task Description

Find the largest number in a list of integers.

## Requirements

### Functional Requirements

1. Accept a list of integers as input
2. Return the maximum (largest) value in the list
3. Handle negative numbers
4. Handle lists with single element

### Input Specification

- **numbers**: A list of integers (at least one element)
- **Return**: An integer representing the maximum value

### Constraints

- List length: 1 to 10,000 elements
- List will always contain at least one element
- No built-in max() functions allowed
- Time complexity: O(n) where n is list length

## Examples

### Example 1: Positive numbers

**Input**: [3, 7, 2, 9, 1]
**Output**: 9
**Explanation**: 9 is the largest number in the list

### Example 2: Negative numbers

**Input**: [-5, -2, -8, -1]
**Output**: -1
**Explanation**: -1 is the largest (least negative)

### Example 3: Mixed positive and negative

**Input**: [-3, 5, -1, 2]
**Output**: 5
**Explanation**: 5 is the largest value

### Example 4: Single element

**Input**: [42]
**Output**: 42
**Explanation**: Only element is the maximum

### Example 5: All same values

**Input**: [7, 7, 7, 7]
**Output**: 7
**Explanation**: All elements equal, any is maximum

## Test Cases

Common mistakes:
