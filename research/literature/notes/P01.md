## Paper Metadata
- **Title**: Towards Understanding the Characteristics of Code Generation Errors Made by Large Language Models
- **Source**: 47th IEEE/ACM International Conference on Software Engineering (ICSE 2025), Research Track
- **arXiv ID**: 2406.08731
- **Date**: Submitted June 13, 2024; Last revised February 12, 2025 (v3)
- **Authors**: Zhijie Wang, Zijie Zhou, Da Song, Yuheng Huang, Shengmai Chen, Lei Ma, Tianyi Zhang

## Key Findings

1. **Two-Dimensional Error Framework**: Semantic characteristics (root causes) + Syntactic characteristics (error localization)
2. **Non-Trivial Errors**: LLMs generate multi-line errors across various locations with diverse root causes
3. **Six LLMs Analyzed**: CodeGen-16B, InCoder-1.3B, GPT-3.5, GPT-4, SantaCoder, StarCoder on HumanEval
4. **Error-Complexity Correlation**: Analyzed relationship between error types, task complexity, and pass rates
5. **Localization Challenges**: Identified difficulties in pinpointing and fixing LLM code errors

## Error Patterns Identified

**Semantic Characteristics** (high-level root causes):
- Missing condition - code lacks necessary conditional logic
- Wrong (logical) direction - fundamentally incorrect solution approach
- Incorrect condition - conditional logic present but wrong

**Syntactic Characteristics** (error localization):
- Incorrect code blocks - structural errors in multi-line segments
- Incorrect function arguments - wrong parameters or argument order
- Incorrect return values - return type or value errors

**Sample Size**: 558 incorrect solutions analyzed via open coding and thematic analysis

## Design Implications

1. **Explicit Conditional Syntax**: Make conditional logic unambiguous and visible
2. **Control Flow Clarity**: Reduce complexity in multi-line code constructs
3. **Strong Function Typing**: Enforce parameter and return type constraints
4. **Error Isolation Features**: Language constructs that localize errors to specific lines/blocks
5. **Intent-Revealing Syntax**: Grammar that makes semantic intent transparent
