2. **Fine-Grained Classification**: 17 specific mistake types across seven categories
3. **Novel Categories**: Four mistake categories not identified in previous work
4. **Root Cause Framework**: Six underlying reasons from various analytical perspectives
5. **Software Context Focus**: Emphasizes external dependencies and real-world scenarios (not just standalone functions)
6. **Large-Scale Study**: Python and Java code analysis, nearly 11x more coding questions than prior studies

## Error Patterns Identified

**Seven Non-Syntactic Categories**:

1. **Condition Error**: Incorrect conditional logic or missing conditions
2. **Index Issue**: Array/list indexing mistakes (off-by-one, out-of-bounds)
3. **Return Issue**: Wrong return values, missing returns, incorrect return types
4. **Math Knowledge Issue**: Mathematical computation errors, algorithm misunderstandings
5. **API Usage**: External library/API misuse, wrong parameters, incorrect methods
6. **Erroneous Pattern**: Anti-patterns, inefficient implementations, design mistakes
7. **Incorrect Functionality**: Fundamentally wrong solution approach

**17 Specific Mistake Types** (detailed breakdown requires full paper)

**Six Underlying Reasons** (perspectives):
- Conceptual misunderstanding
- Context blindness
- Dependency confusion
- Domain knowledge gaps
- Pattern misapplication
- Semantic drift

**Language Coverage**:
- Python (primary)
- Java (secondary)
- Nearly 11x larger dataset than prior studies

## Design Implications

1. **Context-Aware Language Features**: Support for external dependencies and real-world scenarios
2. **API Contract Clarity**: Make external API usage patterns explicit and verifiable
3. **Index Safety**: Built-in protections against index-related errors
4. **Return Value Enforcement**: Strong typing and validation for return statements
5. **Domain-Specific Constructs**: Language features that encode domain knowledge (especially math)
6. **Pattern Recognition Support**: Language should guide toward correct patterns, away from anti-patterns
7. **Dependency Management**: First-class support for external library context
